# Contributing

One lab, this repository. Do not edit sibling labs from here.

- Code you add is MIT. Writing and drawings you add are CC BY-NC-SA 4.0.
- Do not paste vendor articles, images, or problem sets. Cite with a link and a paraphrase, and keep the source id in the room ledger.
- The chat quotes the index. It does not invent a product fact. Do not lower the confidence floor in `shared/pybot-chat/engine.js`.
- No trackers, no CDN, no LinkedIn, no Spotify, and no pay or hiring promises.
- Brand links stay on cyphermonkeylabs.com, linktr.ee/CypherMonkey, and github.com/CypherMonkeyLabs.
- Run `node scripts/validate_lessons.mjs`, `python3 scripts/licence_manifest.py`, and `python3 scripts/csp_check.py` before you open a pull request.
