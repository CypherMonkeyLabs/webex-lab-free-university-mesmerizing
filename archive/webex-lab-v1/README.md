# Archived Webex Lab v1

This folder is the previous practice console. The university at the repository root replaces it as the front door. The console stays because it has interactive pieces the Canon rooms do not replay:

- Dial-plan simulator
- Flow designer with activity names
- Control Hub-style click path
- 3D topology, with a flat map when WebGL is unavailable
- Boss incidents and the interview desk
- Sixteen tracks of lesson JSON

Open `campus/index.html` from a local server or from GitHub Pages. Paths inside `campus/` are relative.
