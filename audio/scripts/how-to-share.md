# How to practise and share

Two voices. About seventy seconds when read aloud. Drop an mp3 at `audio/how-to-share.mp3` if you generate one. This build has the script only.

**A:** Practise in three places. The room quiz, the big practice quiz, and the flashcard deck. The ports game is a drill, not a firewall ticket.

**B:** Share the lab from the repository link in the top bar. Rate it there. A comment or a correction goes to the contact form on cyphermonkeylabs.com, the section marked contact. There is no email address on this site.

**A:** Save for offline from the top bar, or download the zip. The pages use relative links so the folder still opens on GitHub Pages.

**B:** If a sentence is not cited, treat it as a study note and check the room again.
