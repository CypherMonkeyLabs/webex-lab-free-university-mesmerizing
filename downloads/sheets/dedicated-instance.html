Dedicated Instance

One page pulled from the Canon rooms named in the source column. Open the room before you quote a number in a design. This is not a copy of a Cisco document.

CheckWhat the room saysSource
What is Dedicated Instance, in the introduction’s first definition?A dedicated cloud instance based on Unified CM, integrated with Webex Calling, and an add-on. [cite:1]T5-R01-what-dedicated-instance-is.html
Which application is Americas-only?Cisco Emergency Responder. [cite:1]T5-R01-what-dedicated-instance-is.html
Can a Webex Calling user join a Dedicated Instance hunt group?No. The article uses that as the example of features that are not harmonized. [cite:1]T5-R01-what-dedicated-instance-is.html
What sets the call-processing node count?Knowledge Workers and Common Area devices from the First Time Setup Wizard. The Dedicated Instance team sizes the apps. [cite:1]T5-R01-what-dedicated-instance-is.html
What is the full-cluster device figure?Up to 8 call-processing servers or approximately 50,000 devices on version 14 and above, and 50,000 configured devices as the partner limit. [cite:1]T5-R01-what-dedicated-instance-is.html
How many end users can be in the cluster?A maximum of 160,000, configured or synchronized over LDAP. [cite:1]T5-R01-what-dedicated-instance-is.html
When is SME eligible, and whose network carries SME replication?At three clusters. Replication traverses the Cisco backbone, not the customer network. [cite:1]T5-R01-what-dedicated-instance-is.html
