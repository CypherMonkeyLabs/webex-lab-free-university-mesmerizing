Devices and provisioning

One page pulled from the Canon rooms named in the source column. Open the room before you quote a number in a design. This is not a copy of a Cisco document.

CheckWhat the room saysSource
What two claims does Control Hub offer?MAC address, or an activation code. A blank MAC generates the code. [cite:1]T2-R04-devices-provisioning.html
How long is the code?16 digits. [cite:2]T2-R04-devices-provisioning.html
How long does an MPP code last?30 days. A Room device code lasts 7 days. [cite:2]T2-R04-devices-provisioning.html
Which firmware can type the code?MPP firmware 11.3.1 SR2 or later. [cite:1]T2-R04-devices-provisioning.html
How many devices on a professional workspace?Up to five of the phone types the article names. [cite:3]T2-R04-devices-provisioning.html
What is the default calling service for a Room or Desk workspace?Call on Webex, which is 1:1 and non-PSTN. [cite:3]T2-R04-devices-provisioning.html
Which CSV device types cover RoomOS?WEBEX or WEBEX_CALLING. IP is for MPP, ATA, and DECT. [cite:1]T2-R04-devices-provisioning.html
