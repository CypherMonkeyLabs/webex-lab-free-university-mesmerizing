Webex Calling

1. What does a registration-based Local Gateway trunk allow, and what does not?

t9xctu: registration trunks are CUBE only and up to 250 concurrent calls. Certificate trunks are the path above 250 and can use other device types the article lists. Endpoints do not register through the Local Gateway.

2. How do you tell Local Gateway from Survivability Gateway?

Local Gateway terminates the Calling trunk. BRKCOL-2312 describes Survivability Gateway as a site gateway, managed from Control Hub, that routes internal, external, and emergency calls during an outage. It is not a registration proxy for the phones.

3. Which SRTP cipher does commercial Webex Calling accept, and which does Webex for Government require?

jr1i3r: commercial crypto is AES_CM_128_HMAC_SHA1_80, and the article says Webex Calling only supports SHA1_80. For Government that SHA1 step is not applicable. AEAD_AES_256_GCM is mandatory, the trunk is certificate-based, and CUBE is the only SBC t9xctu names.

4. Why does a certificate trunk stay offline in Control Hub when the dial-peer is up?

t9xctu: every SIP transaction the gateway starts, including OPTIONS, needs a Contact header with the gateway FQDN. Without that FQDN, Control Hub does not show the gateway online.

5. What is destination-pattern BAD.BAD for?

What is destination-pattern BAD.BAD for: jr1i3r: it is a dummy pattern required when outbound calls are routed with an inbound dial-peer group. It is not a number you assign to a user.

6. In what order does IOS XE match an inbound SIP call?

Cisco document 211306: incoming URI via, then request, then to, then from, then called-number, then calling number or answer-address, then destination-pattern against the ANI. The first matching criterion wins. It is not a digit-by-digit hunt.

7. What does dial-peer hunt 0 do?

What does dial-peer hunt 0 do: Longest match, then explicit preference (a lower number is better), then random. huntstop stops the gateway from trying the next peer after a failure.

8. What does Control Hub Config Validation actually check?

Article 2zx7fg is for registration-based Local Gateways. It checks the Webex-facing dial-peers, tenant, and trustpoint. It does not validate the PSTN or PBX dial plan.

9. Which debug habit does the Local Gateway article want before you leave debug voip ccapi inout running?

jr1i3r’s method is Diagnostic Signatures. DS 64224 disables all debugs and uninstalls the signatures at 75 percent CPU. The IOS routing article is where ccapi inout is printed, for a call that fails the first peer and hunts.

10. What does ICE-Lite fail to optimize?

jr1i3r: stun usage ice lite on the Webex-facing dial-peers lets media optimize. Recording and other services that need cloud media cannot be optimized that way.

11. Where do unmatched calls go during a Unified CM coexistence?

The configuration workflow sends destinations Webex Calling does not own, including Unified CM extensions it has not learned, to the Local Gateway. Each moved group needs dial-plan updates on Unified CM, Webex Calling, and the gateways.

12. How does a calling search space choose a pattern?

CallManager System Guide, Release 4.0(1), chapter Partitions and Calling Search Spaces: digit analysis searches every partition in the CSS and keeps the closest match. If two partitions have an equal match, the one listed first wins. The null partition is searched last. The CUCM 12.5 troubleshooting chapter restates the same rule.

13. What happens when a line and a device both have a CSS?

The System Guide says CallManager concatenates them and places the line CSS in front of the device CSS. A combined CSS clause is capped at 1024 characters including separators. An individual CSS is 512.

14. Which recording provider is the default?

Cite both sentences in nhvl4hw. One says Webex is the default value if you only have Calling. A later sentence says Dubber is chosen by default because Dubber Go is included with the user entitlement. This Canon does not screenshot the live control. Webex retention is one year and 100 GB. Dubber Go is 30 days in the user portal.

15. What must an extension-only user’s emergency callback number be?

The location default, or another telephone number from that same location. A number from a different location is not that rule.

16. What does 933 prove in the United States and Canada?

What does 933 prove in the United States and Canada: It tests emergency-call email generation. It does not alert public safety personnel. Kari’s Law notification is a separate Control Hub toggle.

17. Name the three PSTN families for a Calling location.

Webex Contact Center

23. Which queue patterns exist, and which queue types get them?

If a screen shows another name, read np2fdx and ubg5qd before you teach it.

24. What is the agent cap on an agent-assignment queue?

25. How do skills in the flow differ from skill criteria on the queue?

np2fdx: queue skill criteria select implicit agents. The team does not associate those skills. Skills injected in the flow can relax over call-distribution groups. Weights do not change Longest Available. Boolean, text, and enum skills decide eligibility. They are not a score. Best Available uses proficiency, and a less-than test is scored as 10 minus the value.

26. What does a variable queue do to the routing algorithm?

Insufficient Information means position is valid and estimated wait is −1. The Erlang number in the Canon lab is a study model, not this EWT.
