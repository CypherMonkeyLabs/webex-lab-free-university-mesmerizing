# Chrome

Header, one-row banner, left slide-in menu, phone bar, and footer styles.

| File | Role |
| --- | --- |
| `frame.js` | Banner, menu button, slide-in menu, footer fallback |
| `frame.css` | Menu and banner layout |
| `phone-nav.js` | Phone bottom bar: Menu, Learn, Diagrams, Play, Listen |
| `footer.css` | Boxed disclaimer and the glowing three-icon row |
| `polish.css` | Glow on menu, diagrams, play, listen, and downloads |
| `brand.js` | Glasses monkey, GitHub mark, drawn 3D Linktree mark |
| `polish.js` | About block with those same three links |

`node kit/sync.mjs` copies these from the live `assets/` files. See `docs/KIT.md`.
