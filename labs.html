Hands-on Labs

Five study models in this browser. They cite the sentence they imitate. They are not Unified CM, not a contact-center tenant, and not a calling-search-space trace from a live cluster.

Dial plan / route translator

Article 32gfts: the Unified CM dial plan normalizes numbers as +E.164, and Webex Calling sends unmatched calls to the Local Gateway. Type a national number or an extension.

Run the translator.

Flow Designer simulator

Rules from nhovcy4. Start Flow cannot be removed. Validation starts off. Publish stays disabled until validation is on and this model’s checks are clear.











CSS / routing-decision explorer


This walker follows the Cisco CallManager System Guide, Release 4.0(1): every partition in the calling search space is searched, the closest match wins, and partition order breaks a tie. The null partition is last. It is a study model of that chapter, not a live CUCM. nbedetf still says a complex dial plan is a reason to consider staying on premises.










Try 911 on CSS-OrderTrap (internal is listed first; 911 is still the closer match). Try 1234 on CSS-SRND (12XX beats 1XXX). Try 2345 on CSS-SRND (equal 23XX patterns, partition A wins). Try 0000 on any CSS (null partition, searched last).




Walk a CSS.








CUBE dial-peer matcher


Study model of Cisco document 211306. Inbound SIP checks URI via, URI request, URI to, URI from, then called number, then calling number, then destination-pattern on the ANI. The first criterion that matches wins. Outbound uses hunt 0: longest match, then the lower preference number. This is not a router.















Match a peer.








WxCC routing strategy and queue


Patterns follow np2fdx and ubg5qd. A pattern the queue type does not offer is refused. The wait number is an Erlang C study model. Webex Contact Center estimated wait is the Get Queue Info rule in nhovcy4, including −1 when wait does not apply. Do not quote this Erlang number as the product’s EWT.
















Run the queue.
