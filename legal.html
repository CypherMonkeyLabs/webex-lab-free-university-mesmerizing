Privacy

This site does not include an analytics tag, an advertising tag, or an account. A search of the HTML and JavaScript in this checkout found no analytics loader. Preferences (theme, text size, the welcome tour, the guide’s voice choice, and the monkey’s height) stay in this browser’s local storage. The service worker caches pages for offline reading on this origin. Read-aloud uses the browser speech engine. Voice input, when the browser has it, stays in the page. The guide does not send a question to a server: window.CANON_GUIDE.endpoint is left unset.

Accessibility

Pages start with a skip link. The menu closes with Escape and can be moved with the arrow keys. Text size, font color, theme, and a reduce-motion control are in Display. The contrast theme is one of those themes. The guide can be dragged and dismissed. If speech recognition or speech synthesis is missing, the page says so and the text box still works. This is not a formal accessibility audit.
