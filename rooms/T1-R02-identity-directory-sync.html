00 · Header

T1 · Control Hub & Platform Foundations

Identity & Directory Sync

Directory Connector is one Windows instance per Active Directory domain. SCIM 2.0 is a REST sync with no on-premises connector. Org SSO maps uid. Partner SSO maps mail. A dry run comes before the first full sync, and invite suppression requires SSO.

Room T1-R02 Version v0.1 last-verified: 2026-10-14 Difficulty L2 Est. time 80–100 min Prereq T1-R01 Reading 22 min

Key takeaways

  • One Directory Connector instance serves one Active Directory domain. Download it from Control Hub. A trial or any paid subscription is required to reach the software. [cite:1]
  • The only required cloud attribute is uid. Cisco recommends mail or userPrincipalName, and the chosen attribute must be in email format. [cite:1]
  • Do a dry run before the first full synchronization. Incremental sync stays disabled until a full sync has completed. Group synchronization requires a full sync. [cite:1]
  • Organization SSO uses a SAML 2.0 NameID of transient and a uid claim. Partner SSO uses mail, rather than uid. [cite:2]
  • Commercial SCIM tenant URL is https://webexapis.com/identity/scim/OrgId/v2. Webex for Government uses https://api-usgov.webex.com/identity/scim/OrgId/v2. The manually retrieved bearer token is valid for 365 days. [cite:3]

01 · Executive summary

Five lines, then why it matters

  • Directory Connector runs on Windows Server 2025, 2022, 2019, or 2016, requires TLS 1.2 and .NET Framework 4.5, and needs Active Directory forest functional level 2 or higher. [cite:1]
  • The connector sign-in account is the same user as a full administrator in Control Hub. By default the service uses the local system account to read Active Directory. [cite:1]
  • New accounts can be Active before first sign-in when you verify domains, integrate SSO, and suppress automatic email invites. Invite suppression requires the SSO integration. [cite:1]
  • With more than one IdP, Webex supports SAML, OpenID Connect, and Webex Identity. An extra IdP stays inactive until a routing rule exists. Directory Sync or Entra ID blocks SAML just-in-time create and update. [cite:4]
  • SCIM 1.1 synchronizes users only. SCIM 2.0 adds groups. The Entra ID Wizard is the path that also synchronizes rooms and avatars, through Microsoft Graph. [cite:3]
Why it matters. Calling extensions, license templates, and contact-center agents all start as people in this identity store. A doubled routing prefix later in T2-R03 is usually an Active Directory attribute that already contained the prefix.

Tip

If Directory Sync or Entra ID is enabled, SAML just-in-time create or update will not work. The multiple-IdP article states that directly. [cite:4]

Gotcha

Entra ID does not synchronize null values. Setting an attribute to NULL does not delete or patch that value in Webex. [cite:3] A userPrincipalName that does not match the email in Control Hub provisions a new user instead of matching the existing one. Webex uses the email address as the username, and the default map is userPrincipalName to userName. [cite:3]

04 · Ecosystem

Ecosystem and sister technologies

Identity is the sister that Control Hub, Calling, and Contact Center all read. This section names the neighbors before the flow trusts a click-path. The hub ecosystem map is the cross-track picture.

Glossary

Directory Connector
The Windows software you download from Control Hub and install on a trusted Windows server. One instance serves one Active Directory domain. [cite:1]
Dry run
A test of the synchronization process. You must do a dry run before a full synchronization. [cite:1]
Full synchronization
The sync that turns directory synchronization on for a new installation, and the sync required for groups. [cite:1]
Incremental synchronization
A sync of changes. The dashboard action is disabled when synchronization is paused or disabled, when a full sync has not completed, or when a sync is in progress. [cite:1]
uid
The only required cloud attribute in Directory Connector attribute mapping. It must come from an Active Directory attribute in email format. [cite:1]
SCIM
The REST API that keeps the user list in sync when someone is created, updated, or removed in the Entra application. No on-premises connector. [cite:3]
Bearer token
The secret Entra provisioning uses. The manual retrieval path in the SCIM article says the token is valid for 365 days. [cite:3]
Routing rule
The rule that tells Webex which IdP to use when more than one is configured. Skipping it leaves the IdP inactive. [cite:4]
Hybrid Directory
Named among the Hybrid Services that data residency says are supported in the region, together with Hybrid Calendar, Hybrid Calling, Video Mesh, Hybrid Data Security, and Hybrid Messages. [cite:5]

06 · Config

Click paths

  1. Confirm a trial or paid subscription, then download Directory Connector from Control Hub so the installer is the current build. Upgrades after install are reported through the software. [cite:1]
  2. Install on Windows Server 2025, 2022, 2019, or 2016. Confirm TLS 1.2 and .NET Framework 4.5. Confirm the forest functional level is 2 or higher. [cite:1]
  3. Sign in with the same account as a full Control Hub administrator. Leave the service on the local system account, or set another account in Windows services if that account must read the domain. [cite:1]
  4. Map uid to mail or userPrincipalName. Both must be email format. Map any other attribute only when you can still satisfy that format. [cite:1]
  5. If room objects live in the directory, check Identify Room so room data stays separate from user data. [cite:1]
  6. Run a dry run. Read the event view. Then start a full synchronization. Incremental sync is available after that full sync completes. [cite:1]
  7. Optional Active-before-sign-in path: add and verify the email domains, optionally claim them, integrate SSO, then suppress automatic invites. Suppression requires SSO. [cite:1]
  8. For organization SSO, set NameID format to transient and send uid. For partner SSO, send mail. [cite:2]
  9. For a custom Entra SCIM 2.0 app: Enterprise applications, New application, Integrate any other application you don't find in the gallery, Provisioning mode Automatic, Visible to users set to No. [cite:3]
  10. Copy the Organization ID from the customer view: organization name at the bottom left. Paste it into the tenant URL for the offer you use. Get the bearer token from Apps > Service apps, or from the manual idbroker URL while signed in as a full admin in an incognito window. Test Connection, then save a notification email. [cite:3]
  11. Assign one test user before the rest. Only assigned users and groups are synchronized. [cite:3]
  12. If you add a second IdP, add a routing rule or the IdP stays inactive. You need the Full Admin role. [cite:4]

09 · Self-question ladder

Twelve rungs

L0What is Directory Connector?

Windows software from Control Hub that synchronizes one Active Directory domain into the Webex organization. [cite:1]

L0What is the only required mapped field?

uid. [cite:1]

L1Why does a dry run exist?

The guide says you must do a dry run before a full synchronization. [cite:1]

L1What breaks if SSO is skipped and invites are suppressed?

Invite suppression requires the SSO integration, so the suppression step is not available as a standalone switch. [cite:1]

L2How does an organization SSO assertion name the user?

The IdP claim includes the uid attribute, and NameID format is transient. [cite:2]

L2How does partner SSO differ?

The claim is mail, rather than uid. [cite:2]

L3Which SCIM generation synchronizes groups and still skips rooms?

SCIM 2.0. Rooms and avatars are Wizard-only, through Microsoft Graph. [cite:3]

L3How long is the manual SCIM bearer token valid?

365 days. [cite:3]

L4Why would SAML JIT create fail while Directory Connector is healthy?

If Directory Sync or Entra ID is enabled, SAML JIT create or update will not work. [cite:4]

L4What proves a second IdP is configured and still unused?

Control Hub can add the IdP and leave it inactive until a routing rule exists. [cite:4]

L5Where does the Calling routing prefix belong?

In the location dialing settings, not already inside the Directory Connector extension. T2-R03 cites that rule. [cite:7]

L5Can this identity move to another GEO later?

13 · Interview

Oral answers

30 seconds. Directory Connector is one Windows instance per Active Directory domain. The only required attribute is uid, and I map mail or userPrincipalName. I dry-run, then full-sync. Invite suppression waits for SSO.

2 minutes. Supported servers on the September 15, 2026 guide are Windows Server 2025, 2022, 2019, and 2016, with TLS 1.2 and .NET Framework 4.5, and forest functional level 2 or higher. The connector login is a full Control Hub admin. The service account that reads the directory defaults to local system. Groups need a full sync. Incremental sync stays off until that full sync exists. Organization SSO is SAML 2.0 with a transient NameID and a uid claim. Partner SSO sends mail.

30 seconds, SCIM. SCIM needs no on-premises connector. Commercial tenant host is webexapis.com. Government host is api-usgov.webex.com. SCIM 2.0 synchronizes users and groups. Rooms and avatars stay on the Entra ID Wizard.

2 minutes, collisions. If Directory Sync or Entra ID is already on, SAML just-in-time create and update will not run. A second IdP stays inactive until a routing rule exists. A userPrincipalName that is not the Control Hub email creates a new user. Entra will not push a null, so clearing an attribute in Entra leaves the Webex value. The manual bearer token lasts 365 days, and I mint it as a full admin in a private window.

What you will say about Calling. The extension stored in the directory is the bare extension. The routing prefix is added by Webex Calling, and the dial-plan article says the directory must not already contain it.
