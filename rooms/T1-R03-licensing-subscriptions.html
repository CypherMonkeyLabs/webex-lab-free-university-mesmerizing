T1 · Control Hub & Platform Foundations

Licensing & Subscriptions

Automatic assignments grant Calling, Meetings, Messaging, and Contact Center when a person is added. A license typed onto a new user at creation skips that template. Webex spends the oldest subscription first. Calling still needs a location and an extension or number. A professional workspace license does not downgrade to common area.

Room T1-R03 Version v0.1 last-verified: 2026-10-14 Difficulty L2 Est. time 70–90 min Prereq T1-R01, T1-R02 Reading 20 min

Key takeaways

  • Organization and group templates combine. If one template adds a license and another removes the same license, the user still receives it. [cite:1]
  • Existing users is checked only for the save you are making. The next visit shows it unselected. Preserve licenses for existing users is selected for you when you choose Existing users. [cite:1]
  • Nested groups do not inherit the parent group’s license assignment. The groups hierarchy in Control Hub is flat. A user’s effective licenses are still the combination of every group assignment they belong to, including the parent, when those assignments are applied to them. [cite:1]
  • Webex Calling standard and Customer Assist cannot both be assigned to one user. Webex Attendant Console requires the Calling service set to Professional. [cite:2]
  • A workspace upgraded to the professional workspace license cannot be downgraded to a common area workspace license. A user downgrade from professional to standard loses provisioning and configuration for the affected users. [cite:3]

01 · Executive summary

Five lines, then why it matters

  • Path for an organization template: Management > Users > Licenses, then Set up or Edit. Services listed in the wizard are Calling, Meetings, Messaging, and Contact Center. [cite:1]
  • People can use the services when they become Active, which the article defines as the first sign-in to Webex. A specific license assigned at user creation blocks the automatic assignment. [cite:1]
  • Multiple subscriptions on one assignment are spent oldest first. Subscription creation dates are visible in Control Hub. [cite:1]
  • Two different Contact Center licenses on two groups resolve to the Premium agent license. The same service is not consumed twice. Separate Meetings sites can still grant one Meetings license each. [cite:1]
  • Calling auto-assign needs an E.164 work number that is pre-provisioned on a location and not already assigned. The Calling template article is dated June 10, 2025, so those sentences stay re-check. [cite:4]
Why it matters. A Calling design that “has licenses” and a Calling design that can place a call are different. The second one has a location and a free number. Contact-center agent type is a license choice in this same console.

03 · Concept deep-dive

Templates, then the Calling exception

Automatic licensing grants Webex licenses to new users without a manual assignment for each person. The organization path is Management, Users, Licenses. The group path is Management, Groups, the group, Assignments. [cite:1] Webex does not support auto-assignment to Active Directory distribution groups. Synchronize groups that use a Group Policy. 04 · Ecosystem

Ecosystem and sister technologies

Glossary

License assignment
An organization or group template that grants selected services to future users, and optionally to existing users when you save. [cite:1]
Active
The state the template article uses for first sign-in, when people can use the associated services. [cite:1]
Preserve licenses
The default when you apply a template to existing users. Clear it to remove licenses the template no longer includes. [cite:1]
Host
A Meetings account type that decreases the meetings license count by one. [cite:1]
Attendee
A Meetings account type that does not decrease the meetings license count. The site must have Attendee account enabled. [cite:1]
Call on Webex
The basic default the article names as 1:1 call, non-PSTN, applied with basic messaging and free Webex Meetings when you have not stated otherwise. [cite:1]
Professional workspace
The Calling workspace license you can upgrade to. The upgrade article says you cannot downgrade it to common area. [cite:3]
Customer Assist
A license the individual-edit article says cannot sit on a user together with Webex Calling standard. [cite:2]
Work phone number
The directory field Calling auto-assign uses to find a pre-provisioned E.164 number and its location. [cite:4] re-check

06 · Config

Click paths

  1. Sign in to Control Hub. Management > Users > Licenses. Set up on the first visit, Edit after that. [cite:1]
  2. Select Calling, Meetings, Messaging, or Contact Center. For Meetings, choose Host or Attendee on the next page. [cite:1]
  3. Apply scope: Future users, or Existing users. Leave Preserve licenses checked unless this save should remove licenses. [cite:1]
  4. For a group, Management > Groups > the group > Assignments > Set up or Edit. The same services and the same scope choices appear. [cite:1]
  5. To stop future automatic assignment, open the same Licenses tab and use the trashcan, then Delete. Previously assigned licenses stay. [cite:1]
  6. For one person, Users > the user > Summary > Licenses > Edit Licenses. Choose the subscription and Save. [cite:2]
  7. If Calling settings error immediately after the add, remove the Calling license and assign it again. [cite:2]
  8. For a pending external user, Users > External users > Services > Edit Licenses, clear the licenses, Save, then add the user again with the license you want. [cite:2]
  9. To upgrade a workspace: Management > Workspaces > Calling gear > Cisco Webex Calling > Professional workspace > Save. [cite:3]
  10. To find Calling auto-assign misses: admin.webex.com, Users, Manage Users, Export user list, filter Webex Calling VAR Professional FALSE. [cite:4] re-check

09 · Self-question ladder

Twelve rungs

L0What does an automatic license assignment do?

It grants the selected Webex licenses to new users without a manual assignment for each person. [cite:1]

L0When can the person use the service?

When they become Active, at first sign-in, unless verified domains, SSO, and suppressed invites already made that possible. [cite:1]

L1Why would a template ignore a brand-new user?

A specific license was assigned at creation. API and CSV follow the same rule. [cite:1]

L1Which subscription is used first?

The oldest, until its licenses are used, then the next oldest. [cite:1]

L2What is the union rule?

Organization and group templates combine. A license added by one and removed by the other is still received. [cite:1]

L2Do nested groups inherit?

No. The assignment applies to direct members. The hierarchy is flat. [cite:1]

L3What does Preserve licenses protect?

Licenses already on existing users when you remove them from the assignment. Clear it to remove those licenses, including manually assigned ones. [cite:1]

L3Which Contact Center license wins a group collision?

The Premium agent license. [cite:1]

L4Why can Calling stay off after the template is correct?

The user needs a location and an extension or number. Auto-assign looks up an E.164 work number that is pre-provisioned and free. [cite:4]

L4What does a professional workspace upgrade refuse afterward?

A downgrade to the common area workspace license, including when you switch subscriptions. [cite:3]

L5What is lost on a professional-to-standard user downgrade?

All provisioning and configuration information for the affected users. The article says to treat that as a last resort. [cite:3]

L5Which Calling client versions lose Calling services?

Webex Calling versions 44.3 or earlier. [cite:3]

11 · Quiz

Twelve questions

Q1MCQ

Which subscription is consumed first?

Answer

The oldest, then the next oldest. [cite:1]

Q2MCQ

Does Existing users stay selected?

Answer

No. After you save and leave, the next visit shows it unselected. [cite:1]

Q3Scenario

The org template adds License A. The group template removes License A and adds License B.

Answer

The user receives both A and B. [cite:1]

Q4MCQ

Do nested groups inherit the parent assignment?

Answer

No. [cite:1]

Q5MCQ

Deleting a template removes licenses already on users?

Answer

No. It stops automatic assignment for future members. [cite:1]

Q6MCQ

Two Contact Center licenses from two groups become which license?

Answer

Premium agent. [cite:1]

Q7MCQ

Can one user hold Calling standard and Customer Assist?

Answer

No. [cite:2]

Q8MCQ

Attendant Console requires which Calling license?

Answer

Professional. [cite:2]

Q9MCQ

Can a professional workspace return to common area?

All provisioning and configuration information for the affected users. [cite:3]

Q11Scenario

Calling auto-assign and the work number is not E.164.

Basic messaging, free Webex Meetings, and Call on Webex (1:1 call, non-PSTN). [cite:1]

13 · Interview

Oral answers

30 seconds. Automatic templates cover future users. I can also apply them to existing users for one save. Organization and group templates union. Subscriptions are consumed oldest first. Services are usable when the user is Active.

2 minutes. Preserve licenses is on when I choose Existing users. Clearing it removes licenses, including ones assigned by hand. Deleting the template does not strip people who already have the license. Nested groups do not inherit. Two Contact Center licenses become Premium agent. Host decreases the Meetings count. Attendee does not. A user created with a specific license skips the organization template. The basic defaults, if I leave them, are basic messaging, free Meetings, and Call on Webex.

30 seconds, Calling. Calling still needs a location and an extension or number. Auto-assign looks up an E.164 work number that is already on a location and not assigned. That article’s header is June 10, 2025, so I say re-check before I treat it as current.

2 minutes, upgrades. I will not put Calling standard and Customer Assist on the same user. Attendant Console means Professional Calling. A professional workspace does not return to common area, even if the subscription changes. A professional-to-standard user change drops provisioning and configuration. Webex Calling 44.3 and earlier lose Calling services. If Calling settings error right after I add the license, I remove it and assign it again.

What you will say about a pending external user. Delete them and add them again to change the license. Removing every license takes them off the External users list.
