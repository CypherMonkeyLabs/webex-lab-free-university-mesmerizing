00 · Header

T1 · Control Hub & Platform Foundations

Locations & Sites

A location is a physical address that can hold both calling and workspaces. A user belongs to one location. A workspace belongs to one location. Webex generates a Location ID. Changing the location time zone does not change the time zone already stored on an auto attendant, hunt group, or call queue.

Room T1-R04 Version v0.1 last-verified: 2026-10-14 Difficulty L2 Est. time 70–90 min Prereq T1-R01 Reading 18 min

Key takeaways

  • Create a location at Management > Locations > Manage location > Create manually. Name, country or region, and street address are required. Webex generates a Location ID. [cite:1]
  • A user can be assigned to only one location. A workspace can be assigned to only one location. Manual add from the location is up to 25 users. [cite:1]
  • A location with Webex Calling cannot be deleted until you click Disable calling. Calling users or workspaces on it cannot be removed from the location until the Webex Calling license is removed. [cite:1]
  • Puerto Rico, Guam, American Samoa, and the U.S. Virgin Islands need the territory as the country when you want territory-specific numbers. Setting the country to the United States blocks those numbers. [cite:1]
  • Calling locations that collided with a workspace location during migration were renamed with a -CALL suffix. Cisco does not support double-assigned workspaces. [cite:1]

01 · Executive summary

Five lines, then why it matters

  • CSV create leaves Location ID blank. CSV edit does not change Location ID. Country in the CSV is the 2-letter code. [cite:1]
  • Floors are a number plus an optional name, on the Floors tab. The workspace-locations API is the floor-capable endpoint. /v1/locations is the calling-locations API after the migration off the previous calling locations API. [cite:1]
  • Adding or removing a user on a location applies the organization license template when one exists, unless the user is on a group template or you are managing them with CSV or the API. [cite:1]
  • A Webex Calling workspace cannot move to a new location until the Calling license is removed, the workspace is moved, and Calling is entitled again. [cite:1]
  • On create, an auto attendant, hunt group, or call queue takes the location time zone. After creation there is no way to alter that feature time zone. A different time zone from the location is not supported. [cite:1]
Why it matters. PSTN, emergency address, survivability, and dial-plan prefixes all hang off this object. A site that is only a name in a spreadsheet is not a location until the address exists and Calling is set up on it.

03 · Concept deep-dive

The address is the anchor

Locations organize users and workspaces by a physical location identified by an address. The same location can carry calling and workspace management. The article’s header on the retrieved page is June 05, 2026. [cite:1]

Street addressRequired. A recognized address can show a map and a pin. An unrecognized address can still be saved, and the map will not display.[cite:1]

Delete, move, and time

SituationWhat the article says happensCite
Delete, Calling not configuredThe location can be deleted. Users and workspaces are unassigned.[cite:1]
Delete, Calling configuredBlocked until you click Disable calling.[cite:1]
Delete while Calling users or workspaces remainBlocked until the Webex Calling license is removed.[cite:1]
CSV deleteManage location > Delete by CSV. The file should contain only locations to delete. Location ID is required. Other cells are ignored.[cite:1]
Move a Calling workspaceRemove the Calling license, move the workspace, then re-entitle Calling.[cite:1]
Change the location time zoneUsers and features linked to the location are not updated. AA, hunt group, and call queue keep the time zone they took at creation.[cite:1]
License template side effectAdding or removing a user on a location applies the organization template if one is defined and preserve license is off. Group templates, CSV, and API are not affected.[cite:1]
Territory numbersPuerto Rico, Guam, American Samoa, and the U.S. Virgin Islands should use the territory as the country. United States as the country blocks territory-specific numbers.[cite:1]

Double-assigned workspaceCisco does not support workspaces assigned to both a workspace location and a calling location. The article recommends assigning one.[cite:1]
Tip

If you are unsure of the country, time zone, or language codes, create one location in Control Hub, download the CSV, and copy the codes. [cite:1]

Gotcha

The map appears only after you pick a suggested address. Saving an unrecognized street still creates the location, and the map stays hidden. [cite:1]

APIs

The previous calling locations API has been fully migrated to /v1/locations. The workspace locations API at developer.webex.com adds floors. Both talk to the same database for the primary operations. [cite:1]

04 · Ecosystem

Ecosystem and sister technologies

Glossary

Location
A physical address that organizes users and workspaces, and can hold calling and workspace management together. [cite:1]
Location ID
The identifier Webex generates at create time. Leave it blank in a CSV row that adds a location. Do not edit it. [cite:1]
Floor
A number, and an optional name, on a location. [cite:1]
Disable calling
The action required before a Calling location can be deleted. [cite:1]
-CALL suffix
The rename applied when a migrated calling location collided with an existing name. [cite:1]
Workspace location versus calling location
Older orgs could have both. A workspace can now be assigned to one location. Double assignment is not supported. [cite:1]
Emergency Service Address
Mandatory for U.S. and Canada Cisco Calling Plan locations in the trunk and dial-plan article. It is set on the location’s PSTN connection. [cite:2]
Routing prefix
A per-location prefix, length 1–7, set under the location’s Calling dialing settings. [cite:3]

06 · Config

Click paths

  1. Sign in to Control Hub. Management > Locations > Manage location > Create manually. [cite:1]
  2. Enter a unique name, a country, and a street address. Pick a suggestion if you want the map. Set email language and time zone. [cite:1]
  3. Add a floor now or later: Floors tab, Add floor, required floor number, optional name. [cite:1]
  4. Create. Record the Location ID. Use What’s next to set up Calling, workspaces, floors, and users. [cite:1]
  5. Bulk: Manage location > Add and edit by CSV. Download data or the template. Leave Location ID blank for new rows. Country is the 2-letter code. [cite:1]
  6. Add users from the location: Actions > View users > Manage users. Manual add is up to 25. You can also paste email addresses separated by commas. Then assign Messaging, Meeting, or Calling. [cite:1]
  7. Or open the user: Profile > User details > Locations, choose the location, Save. [cite:1]
  8. Calling: open the location, Calling tab, Set up calling. PSTN choices are the trunk article’s job after this. [cite:1] [cite:2]
  9. Delete one location with Actions > Delete location. Delete many with Manage location > Delete by CSV and a file whose Location ID column lists only the locations to remove. [cite:1]
  10. For Puerto Rico, Guam, American Samoa, or the U.S. Virgin Islands, set the country to the territory when the numbers are territory-specific. [cite:1]

09 · Self-question ladder

Twelve rungs

L0What is a location?

A physical address that organizes users and workspaces, and can hold calling and workspace management together. [cite:1]

L0Who generates the Location ID?

Webex, when you create the location. [cite:1]

L1Why can’t a Calling location be deleted immediately?

You click Disable calling first. Calling users and workspaces also need the Calling license removed. [cite:1]

L1How many locations can one user have?

One. [cite:1]

L2What does a manual add from the location allow?

Up to 25 users, or a CSV. [cite:1]

L2What is required on a floor?

The floor number. The name is optional. [cite:1]

L3Which API replaced the previous calling locations API?

/v1/locations. Floors are on the workspace-locations API. [cite:1]

L3What does the -CALL suffix mean?

A migrated calling location whose name collided. Duplicate names are not allowed. [cite:1]

L4Why would changing the location time zone leave the auto attendant alone?

The auto attendant, hunt group, and call queue take the location time zone at creation, and that feature time zone cannot be altered afterward. [cite:1]

L4When does location membership change licenses?

When an organization template exists and preserve license is off. Group templates, CSV, and the API are excluded. [cite:1]

L5How do you move a Calling workspace?

Remove the Calling license, move the workspace, then entitle Calling again. [cite:1]

L5Where do territory-specific numbers fail?

When Puerto Rico, Guam, American Samoa, or the U.S. Virgin Islands is given the United States as the country. [cite:1]

13 · Interview

Oral answers

30 seconds. A location is a physical address. One user, one workspace. Webex issues the Location ID. Calling and workspaces can share it. I do not delete a Calling location until I disable calling and remove Calling licenses from the people and places that still have them.

2 minutes. Manual create needs name, country, and street. The map appears when I pick a suggested address. CSV country codes are two letters. New CSV rows leave Location ID blank. Floors need a number. Manual user add from the location is 25. Changing the location time zone does not move an auto attendant, hunt group, or call queue, because those features copied the time zone at creation. A migrated name collision shows up as a -CALL suffix. Double-assigned workspaces are not supported.

30 seconds, territories. Puerto Rico, Guam, American Samoa, and the U.S. Virgin Islands use the territory as the country when the numbers are territory-specific. United States as the country blocks those numbers.

2 minutes, neighbors. PSTN is chosen on the location after it exists. U.S. and Canada Cisco Calling Plan locations need an emergency service address. The routing prefix is also per location. A survivability gateway is per site, in the local network. Adding a user here can apply the organization license template when preserve is off. Group templates, CSV, and the API are the paths that article excludes.

What you will say about an organization-wide location cap. This article does not state one. The 250 figure belongs to how many locations one Webex Calling administrator can be assigned, and that sentence is in the delegation article.
