UCCX discovery into Webex Contact Center

T11-R04. The public migration guide is UCCX to Webex Contact Center, using a discovery tool and bulk operations. It is a manual migration. The tool may not support every new feature. [cite:16]

Reading 11 minWrittenStudy notes

Key takeaways

  • Prepare a WxCC tenant, Control Hub users, and contact-center synchronized users before the tool. [cite:16]
  • The prose says download discovery tool v3.5. The printed jar command uses uccx-to-webexcc-v3.4.jar. Both strings are on the page. [cite:16]
  • Java 8 or above, access to the CCX server, and the CCX administrator credentials are required. [cite:16]
  • A bulk import CSV is limited to 5000 rows. [cite:16]
  • The article prints a recommended CSV import order, starting with MultimediaProfiles.csv and ending with Users.csv. [cite:16]

02 · Map

Extract, edit, zip, import

The tool writes a spreadsheet and a prompts zip. You edit the sheets to match the Webex Contact Center design, then import with bulk operations. [cite:16]

03 · Core

What the opened pages say

Run java -jar uccx-to-webexcc-v3.4.jar -extract. If you omit the port, the console uses 443. The tool writes application-pro.yml, then WebexCC_Bulk_Upload.xlsx and WebexCC_Bulk_Upload_Prompts.zip. A second command with -zip builds WebexCC_Bulk_Upload.zip. [cite:16]

The page says the tool is evolving and may not support all the latest features. Macintosh file names are case-sensitive. [cite:16]

Queue routing types for telephony are longest available agent or skill based. Skill types are text, boolean, enum, or proficiency. User profile types include administrator, supervisor, administrator only, premium agent, and standard agent. The sheet sample for administrator is printed with a missing R in one cell. The accepted-values line spells ADMINISTRATOR. Trust the accepted-values line when they differ, and re-read the live page. [cite:16]

This is not the CCE tenant-to-tenant tool. That tool, n2puc5z, moves Webex Contact Center Enterprise Administration Portal data between tenants. [cite:17]

05 · Flow

Order of operations

  1. Create the WxCC tenant and the users first.
  2. Extract. Edit every sheet against the device-discovery table.
  3. Zip. Split any CSV over 5000 rows.
  4. Import in the printed order. Check the objects in Control Hub.

06 · Config

Clicks the articles print

  • Command printed for extract: java -jar uccx-to-webexcc-v3.4.jar -extract. [cite:16]
  • Command printed for zip: java -jar uccx-to-webexcc-v3.4.jar -zip. [cite:16]
  • Import order begins MultimediaProfiles.csv, Site.csv, UserProfiles.csv, and ends Users.csv. The full list is on the article. [cite:16]
