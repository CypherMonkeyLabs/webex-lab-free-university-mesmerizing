00 · Header

T2 · Webex Calling

Calling Architecture Overview

In the Unified CM migration guide, Webex Calling means the multi-tenant cloud call service. Endpoints register to that cloud. A local gateway is the bridge for PSTN and for calls between Unified CM-registered phones and cloud-registered phones. Cisco Calling Plan and Cloud Connect need no on-premises PSTN equipment. Control Hub is the portal at admin.webex.com.

Room T2-R01Version v0.1last-verified: 2026-10-14Difficulty L2Est. time 70–90 minPrereq T1-R01, T1-R04Reading 18 min

Key takeaways

  • The migration guide’s “Webex Calling” is always the multi-tenant service. Components named there are Control Hub, directory and user provisioning, the Webex Calling platform, supported endpoints, PSTN options, dial plan and number management, and security and compliance. [cite:1]
  • A local gateway is a bridge between the on-premises UC network and the Webex Calling cloud. It can be on premises or partner-hosted. Platforms named in the migration guide are Cisco IOS-XE ISR 1100 and 4000, Catalyst 8200 and 8300, Catalyst 8000V, and certified third-party SBCs. [cite:1]
  • Cisco Calling Plan and Cloud Connect for Webex Calling are cloud PSTN options that do not require on-premises equipment. Cloud PSTN serves Webex Calling users. [cite:1] [cite:3]
  • Entra ID customers use the Entra ID Wizard instead of Directory Connector when the directory moves to Entra ID. [cite:1]
  • The configuration workflow article is dated March 20, 2025. Sentences taken from it stay marked for a fresh read. re-check [cite:2]

01 · Executive summary

Five lines, then why it matters

  • Before the move, phones and Jabber register to Unified CM. Expressway-C and Expressway-E pairs serve MRA and business-to-business. CMS, CMM, and TMS are optional. Unity Connection is optional. [cite:1]
  • After the move, Webex Calling is the cloud call service. Endpoint registration and call routing live there. Webex App on Windows, Mac, Android, and iOS registers directly to Webex Calling. [cite:1]
  • Control Hub assigns a local gateway to a location and then supplies the parameters you configure on CUBE. Those steps register the gateway with the cloud. PSTN for users in that location then comes through the gateway. re-check [cite:2]
  • A trunk terminates on a local gateway or another supported device. A route group holds trunks for distribution or redundancy. Dial plans are global for all users. Pattern language stays in T2-R03. [cite:3]
  • The migration section lists collecting location details: emergency response address, number of users, internet access, and PSTN access. Help paths named in the guide are Webex migration tools in Control Hub, certified migration providers, and Webex Setup Assist. [cite:1]
Why it matters. A design that treats Webex Calling as a second Unified CM misses the registration change. The gateway is a bridge, and the cloud is the call service.

Stay-on-premises list

The guide says customers with these requirements should consider keeping call control on premises: phone models Webex Calling does not support, complex on-premises integrations, a complex dial plan or highly granular classes of service, restrictive or unreliable internet, stringent data-privacy policies, a compliance need for on-premises or in-country recording, third-party integrations without a Webex Calling alternative, and contact-center integrations that are not moving to the cloud yet. [cite:1]

06 · Config

Click paths and the order around them

  1. Sign in at admin.webex.com. The workflow calls Control Hub the management portal for the bundled calling offer. re-check [cite:2]
  2. Complete first-time calling setup: users, numbers, and services. The same article says you can cross-launch to the Calling Admin Portal. re-check [cite:2]
  3. Choose PSTN per location: premises through a local gateway, Cisco Calling Plan, or Cloud Connect. Cloud options in the migration guide need no on-premises equipment. [cite:1]
  4. For a local gateway, assign it to the location in Control Hub, then configure the parameters Control Hub provides on CUBE. re-check [cite:2]
  5. Build trunks and route groups when the premises connection needs distribution or redundancy. Dial-plan patterns stay in T2-R03. [cite:3]
  6. Register Webex App directly to Webex Calling on the platforms the guide names. [cite:1]
  7. If the directory is Entra ID, use the Entra ID Wizard rather than Directory Connector. [cite:1]
  8. Record the location details the migration section names: emergency response address, number of users, internet access, and PSTN access. [cite:1]
