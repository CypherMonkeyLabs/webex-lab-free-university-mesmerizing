00 · Header

T2 · Webex Calling

Dial Plans, PSTN & Routing

Internal dialing is an organization length plus a per-location prefix. Enterprise dial plans are global, one routing choice, and a pattern language with two wildcards that are illegal in the middle. PSTN is chosen per location: Cisco Calling Plan, Cloud Connected PSTN, or premises-based PSTN through a local gateway. Cloud PSTN serves Webex Calling users. Calls that start on the premises do not use it.

Room T2-R03 Version v0.1 last-verified: 2026-10-14 Difficulty L3 Est. time 90–110 min Prereq T1-R01, T2-R02 Reading 17 min

Key takeaways

  • Internal extension length is 2–10 digits, default 4. Routing prefix length is 1–7 and includes the steering digit, so a length of 4 leaves 3 digits for the site. Lengthening extensions does not rewrite speed dials. [cite:1]
  • If extensions repeat across locations, turn off extension dialing between locations. The caller then dials the Enterprise Significant Number: routing prefix plus extension. Directory Connector must not already contain the prefix, or Webex adds it again. User extensions should not start with the steering digit or the outbound dial digit. [cite:1]
  • An enterprise dial plan is global for all users and has one routing choice, a trunk or a route group. Patterns are ESN/on-net, +E.164, or a SIP URI domain. X is one digit. ! is only at the end of an E.164 pattern, once. 617495X3XX and 1617495X3! are illegal. [cite:2]
  • Same route-group priority means random distribution. If the highest-priority trunk is unavailable, a lower priority is tried. The worked example is trunks 1 and 2 at level 1, trunk 3 at level 2. A route group holds 1 to 10 trunks. [cite:2]

03 · Core concepts

Three PSTN choices, one pattern language

Location first

After a location exists, PSTN is assigned there: Cisco PSTN, Cloud Connected PSTN, or premises-based PSTN. The path in the trunk article is Calling > Locations, then Assign or Manage. Cloud PSTN does not carry calls that originate from premises users. [cite:2]

Steering digit is inside the length

Prefix length includes the steering digit. Length 4 means three digits identify the site. Every prefix starts with the steering digit you chose. The outbound dial digit should be a different number, and its default is None. [cite:1]

Headers must agree

A dial plan accepts From and To as E.164 or as extensions. A mix of the two is refused. The article’s example pair is 1-222-333-4444 to 1-555-666-7777, both the same kind of number. [cite:2]

04 · Ecosystem & sister technologies

Glossary, map, sisters, edges

Glossary

Internal extension length
Organization setting, 2–10 digits, default 4. Lengthening it does not rewrite existing speed dials to internal extensions. [cite:1]
Routing prefix
Digits in front of an extension so two locations can reuse the same extension. Length 1–7, unique per location. [cite:1]
Steering digit
The first digit of every routing prefix. It counts inside the prefix length. [cite:1]
Enterprise Significant Number
Location routing prefix plus extension. Required for cross-location extension calls when inter-location extension dialing is off. [cite:1]
Outbound dial digit
Optional digit users dial for an outside line. Default None. Use a different digit from the steering digit. E.164 calls ignore this prefix requirement. [cite:1]
Enterprise dial plan
Global. Applies to all users. One routing choice: a trunk or a route group. Patterns are ESN/on-net, +E.164, or SIP URI domains. [cite:2]
Route group
1 to 10 trunks. Same priority is random. An unavailable higher-priority trunk falls through to a lower priority. [cite:2]
Trunk
Webex Calling to the premises, ending on a local gateway or another supported device. [cite:2]
Unknown extension
2–10 digits, or inbound caller ID that matches no dial-plan pattern. Can be routed to a trunk or route group as a premises call. [cite:2]
Standard Behavior
Recommended unknown-number handling once dial plans exist. Path: Services > PSTN & Routing > Services. [cite:2]
Legacy Behavior
Kept for old local-gateway behavior. The article says not to use it once dial plans are configured. [cite:2]
Caller ID format
+E.164 selects the external CLID. ESN selects the internal CLID. [cite:2]
Verify Call Routing
Simulates a call from a cloud user, workspace, virtual line, or premises trunk. Shows permissions, fraud prevention, digit patterns, intercept, and translation. [cite:2]
Emergency Service Address
Mandatory for U.S. and Canada Cisco Calling Plan locations. The same article later expands ESA as Enterprise Service Address in the validation paragraph. Quote the sentence you mean. [cite:2]
Cloud Connected PSTN
Partner cloud PSTN. No local PSTN hardware for that choice. Still only for Webex Calling users. [cite:2]
Cisco Calling Plan
Cisco’s cloud PSTN. Needs a committed outbound calling plan and a supported country. Read the country in the location wizard on the day you order. The supported-country list changes, so a copied list in this room would be wrong the next time Cisco adds a market. [cite:1]

06 · Config

Click paths

  1. Sign in to Control Hub. Calling > Settings > Service. Scroll to Internal Dialing. Set extension length (2–10, default 4), prefix length (1–7), and the steering digit. [cite:1]
  2. Leave inter-location extension dialing on only when every extension is unique. Otherwise the caller dials prefix + extension for other sites. The toggle defaults to on. [cite:1]
  3. Open the location. Calling > Dialing. Set a unique prefix whose length matches the org recommendation and is still 1–7. Set the outbound dial digit only if users expect an outside-line digit, and do not reuse the steering digit. [cite:1]
  4. If an extension equals a national number, the extension wins. The article recommends an outbound dial digit in that case, and it recommends E.164 for PSTN in both directions. [cite:1]
  5. Create trunks, then a route group of 1–10 trunks with priorities. Confirm the group. You can jump to locations or to dial plans from that screen. [cite:2]
  6. Services > PSTN & Routing > Gateway configurations > Dial Plans > Create Dial Plan. Name it, pick the routing choice, add patterns. Cisco Calling Plan customers may use Services > Calling > Call Routing. [cite:2]
  7. Bulk patterns: Actions, Import Dial Patterns CSV or Export Dial Patters CSV. The export label is printed with that spelling. [cite:2]
  8. Per location, enable routing unknown extensions to the premises and pick the trunk or route group. [cite:2]
  9. Services > PSTN & Routing > Services. Prefer Standard Behavior once dial plans exist. Choose +E.164 or ESN caller ID. Set maximum unknown extension length. If you lengthen extensions and the PSTN is not E.164, incoming PSTN can be treated as local; enforce E.164 before the call reaches Webex Calling. [cite:2]
  10. Run Verify Call Routing on the number you care about. For a U.S. or Canada Cisco Calling Plan location, set the Emergency Service Address. A failed validation does not block premise or CCPP setup, and it can delay emergency handling. [cite:2]

09 · Self-question ladder

Twelve rungs

L1What is the default extension length?

4 digits, and the allowed range is 2–10. [cite:1]

L1What three PSTN choices can a location have?

Cisco PSTN, Cloud Connected PSTN, or premises-based PSTN. [cite:2]

L2Who can place a call through cloud PSTN?

Webex Calling users. Premises-originated calls cannot. [cite:2]

L2What is an ESN?

Location routing prefix plus extension, used when inter-location extension dialing is disabled. [cite:1]

L2How many trunks can a route group hold?

1 to 10. [cite:2]

L3What does priority level 1 on two trunks mean?

Calls are distributed randomly across them. Trunk 3 at level 2 is the fallback when a level-1 trunk is unavailable. [cite:2]

L3Where may ! appear?

Once, at the end, and only on an E.164 pattern. [cite:2]

L3Does *.example.com match example.com?

No. It matches hosts that are subdomains, such as eu.example.com. [cite:2]

L4Why would incoming PSTN be treated as a local premises call?

Extension length was increased and the provider is not sending E.164. Enforce E.164 first. [cite:2]

L4What does Verify Call Routing show beyond the pattern?

Outgoing permissions, fraud prevention, digit patterns, intercept, and translation. [cite:2]

L5Is partition order the tie-break here?

No. That is the CUCM CSS rule in T6-R02. This room’s engine is the Webex pattern language. [cite:3]

L5Which export label is misspelled in the article?

Export Dial Patters CSV. Quote it that way. [cite:2]

11 · Quiz

Twelve questions

Q1MCQ

Default internal extension length?

Answer

Default internal extension length: 4. Range 2–10. [cite:1]

Q2MCQ

Prefix length 4 leaves how many digits for the site?

Answer

Prefix length 4 leaves how many digits for the site: 3. The steering digit is included in the 4. [cite:1]

Q3Scenario

Two stores both use extension 1000. The caller dials 1000.

Answer

With inter-location dialing off, that reaches the match in the caller’s own location. The other store needs the ESN. [cite:1]

Q4MCQ

What is the default outbound dial digit?

Answer

What is the default outbound dial digit: None. [cite:1]

Q5MCQ

Which pattern is illegal?

Answer

Which pattern is illegal: 617495X3XX, because X is in the middle. Also 1617495X3!. [cite:2]

Q6MCQ

Where can ! be used?

Answer

Once at the end of an E.164 pattern. [cite:2]

Q7Scenario

Trunks 1 and 2 are priority 1. Trunk 1 is down.

Answer

A priority-1 trunk that is up still carries the call at random among available priority-1 trunks. Priority 2 is the next setting when the highest priority is unavailable. [cite:2]

Q8MCQ

How many trunks in a route group?

Answer

How many trunks in a route group: 1 to 10. [cite:2]

Q9Scenario

A premises phone needs Cloud Connected PSTN.

Answer

The article says calls originating from premises users cannot access cloud PSTN. [cite:2]

Q10MCQ

Recommended unknown-number handling after dial plans exist?

Answer

Standard Behavior. Legacy Behavior is not recommended then. [cite:2]

Q11Draw

Write one legal ESN and one legal +E.164 wildcard from the article’s table.

Answer

Write one legal ESN and one legal +E.164 wildcard from the article’s table.: 84969XXX or 84969764, and +1408555XXXX or +496100! or +14085551234. [cite:2]

Q12MCQ

Does a longer extension rewrite speed dials?

Answer

Does a longer extension rewrite speed dials: No. [cite:1]

13 · Interview

Oral answers

30 seconds. Internal length defaults to 4. A routing prefix of length 4 includes the steering digit, so three digits name the site. Duplicate extensions mean the caller dials prefix plus extension. PSTN is Cisco, Cloud Connected, or a local gateway, per location.

2 minutes. Enterprise dial plans are global and have one routing choice. I can defend +1408555XXXX, +496100!, and 84969XXX, and I will reject X in the middle and X mixed with !. SIP URI matching is the host only, and *.example.com does not match the apex. Route groups hold up to 10 trunks, random at the same priority. Unknown extensions from 2 to 10 digits go to the premises when that location toggle is on. Standard Behavior is the recommendation after dial plans exist.

30 seconds, cloud PSTN. Cisco Calling Plan needs the committed plan and a supported country. Cloud Connected PSTN is the partner path. Neither one takes a call that starts on the premises.

2 minutes, migration habit. I keep abbreviated dialing with the unknown-extension toggle while a site is only partly moved. I keep the prefix out of Active Directory. I enforce E.164 on the PSTN before I lengthen extensions. I run Verify Call Routing before I argue about a trace. I do not describe this as CUCM closest-match.

What you will not say. You will not claim a Teams dial plan is the same table. You will not invent the Cisco Calling Plan country list from memory.
