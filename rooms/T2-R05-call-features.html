00 · Header

T2 · Webex Calling

Call Features

Hunt groups, call queues, auto attendants, call pickup, and feature access codes are location features in Control Hub under Services > Calling > Features. A hunt group rings a list. A call queue holds callers when agents are busy and is part of the professional license. An auto attendant plays a menu. Pickup answers a coworker’s ringing line. Star codes run the same features from a phone.

Room T2-R05Version v0.1last-verified: 2026-10-14Difficulty L2Est. time 80–100 minPrereq T2-R01, T1-R04Reading 20 min

Key takeaways

  • Hunt-group routing caps: Circular, Top Down, and Longest Idle allow 1,000 agents. Weighted allows 100. Simultaneous allows 50. [cite:1]
  • A call queue is voice-only and part of the Webex Calling professional license. The article recommends voice queues for up to 50 agents and recommends Webex Contact Center for omnichannel or large volume. The maximum table is separate from that recommendation. [cite:2]
  • An auto attendant’s location cannot be changed after it is created. Transfer to operator uses the configured number when the key is pressed, or when no keys are pressed for the no-input timer. The CSV default for that timer is 10 seconds, range 1–60. [cite:3]
  • A user belongs to one call pickup group, and the group is one location. Desk phones pick up with *98. [cite:4] [cite:5]
  • The call-queue article’s retrieved body had no header date. Treat that date as unverified. re-check [cite:2]

01 · Executive summary

Five lines, then why it matters

  • When a hunt group or a call queue sends a call to an agent, that agent’s call forwarding does not apply. [cite:1] [cite:2]
  • Hunt group busy is off by default. Only an administrator enables it, unless agents are allowed to use the FAC codes. Activation is #51, deactivation #52, interrogation #53. [cite:1] [cite:5]
  • Call-queue size is 250 calls. You can set calls in queue from 0 to 250, and the article says not to set 0 because incoming calls are then not allowed. A supervisor can manage 100 agents. Up to 1,000 queues per location. [cite:2]
  • Skill level 1 is highest and 20 is lowest. Default skill is 1. Skill routing uses skill first, then Circular, Top Down, or Longest Idle to break a tie. Calls are not routed to agents in Wrapping Up by default. [cite:2]
  • Call park is *68 after hold and a dial tone. Retrieve is *88. Group park is #58 or *58. Directed pickup is *97. Directed pickup with barge-in is *33. [cite:5]
Why it matters. A sales ring pattern, a held queue, and a menu are three different objects. The agent caps are not interchangeable.

PatternWhat it doesMax agentsCite
CircularCycles through members after the last member who took a call.1,000[cite:1]
Top DownStarts from the top of the list each time.1,000[cite:1]
Longest IdleRings the member idle the longest, then the next.1,000[cite:1]
WeightedSends calls to idle members by the percentages you assign, up to 100%.100[cite:1]
SimultaneousRings all members at once.50[cite:1]

Advance when busy skips members already on a call. If you turn that off and the member has call waiting, the caller hears call-waiting tone until the member declines or becomes idle. Divert when unreachable applies to a network outage, and does not divert users who only have a mobile device. A blank extension uses the last four digits of the phone number. CSV weight is 0–100. Each CSV row holds 50 agents. A hunt group can have 1,000 agents, using continuation rows with the same name and location. [cite:1]

Tip

Keep the 50-agent voice-queue recommendation next to the 1,000-agent maximum. They are different sentences. [cite:2]

Gotcha

Disabling “allow agents to use the hunt group number as caller ID” is rejected while any agent still uses that number as Agent Caller ID. India locations also require the same PSTN provider, country, and zone. [cite:1]

Survivability neighbor

Hunt groups inside survivability mode have a different cap. That cap is T2-R07. The 1,000-agent figures on this page are Control Hub features while the cloud is reachable.

04 · Ecosystem

Ecosystem and sister technologies

Glossary

Hunt group
A number that rings a defined list of users, workspaces, or virtual lines in a chosen pattern. [cite:1]
Call queue
A professional-license voice queue that holds calls until an agent is available. [cite:2]
Auto attendant
A menu that answers and routes to a person, hunt group, or voicemail without a receptionist. [cite:3]
Call pickup group
An administrator-defined set of users in one location who can answer each other’s ringing lines. [cite:4]
FAC
Feature access code, also called a star code, dialed on Webex App or an IP phone. [cite:5]
DNIS
Extra numbers that route to the same call queue while keeping the dialed number’s identity. Up to 100 per queue. [cite:2]
Skill level
1 is the highest skill on a call queue and 20 is the lowest. [cite:2]
Wrapping Up
Agents in this state do not receive queued calls unless that default is changed. [cite:2]

06 · Config

Click paths

  1. Sign in to Control Hub and open Services > Calling > Features. [cite:1]
  2. Hunt group: Add New, choose the location, name, number, and whether agents may use the group number as caller ID. [cite:1]
  3. On Call Routing, pick Circular, Top Down, Longest Idle, Weighted, or Simultaneous and stay inside that pattern’s agent cap. [cite:1]
  4. On Routing Settings, decide Advance when busy, divert when unreachable, divert when busy, and hunt group busy. Busy is off until you enable it. [cite:1]
  5. Call queue: Add new, set location, name, number, calls in queue (not 0), and caller ID. Choose priority or skill, then the pattern. [cite:2]
  6. Auto attendant: Add New, set the location knowing it cannot change, then business hours, after hours, and holiday. Menu keys transfer to a person, hunt group, voicemail, or the operator number. [cite:3]
  7. Call pickup: Add New, one location, unique name, then users, workspaces, or virtual lines. Notification delay is 1–60 seconds. [cite:4]
  8. From a phone, park with hold, dial tone, *68. Retrieve with *88. Pick up with *98. [cite:5]

13 · Interview

Oral answers

30 seconds. A hunt group rings a list. Circular, top down, and longest idle allow 1,000 agents. Weighted allows 100. Simultaneous allows 50. A call queue holds callers and belongs to the professional license. An auto attendant is the menu.

2 minutes. I create all of them under Services, Calling, Features, in a location. A blank extension becomes the last four digits. Agent forwarding does not apply once the feature has sent the call. Hunt group busy is off until an admin enables it. Agents then use #51, #52, and #53. A queue’s recommended voice size is 50 agents, while the table allows more except for weighted and simultaneous. Queue size is 250 and must not be 0. Skill 1 is highest. Pickup is one group per user in one location, and the desk code is *98. Park is *68 after hold. The attendant’s location cannot change, and its no-input default is 10 seconds.

30 seconds, caller ID. I can let agents present the group number. I cannot turn that policy off while an agent still uses it. In India the locations must share PSTN provider, country, and zone.

2 minutes, what I will not merge. I will not treat the 50-agent recommendation as the hard maximum. I will not teach survivability hunt caps as these Control Hub caps. I will not date the call-queue article, because the retrieved page had no header. I will not send omnichannel work to a voice queue when the article points at Webex Contact Center.

What you will say about a missed call on a coworker’s phone. If they share a pickup group, *98 or the softkey answers it. A new group notifies with visual and audio. An existing group defaults to no notification until you change it.
