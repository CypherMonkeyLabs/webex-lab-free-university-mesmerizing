03 · Core

Keep the articles in their lanes

jwkbt2, header April 28, 2026, lists TLS 1.2 and TLS 1.3 and the SRTP key AES_CM_128_HMAC_SHA1_80. Certificates need Server Authentication EKU; Webex does not require Client Authentication EKU. The FQDN in the CN or SAN must match Control Hub, without the port. The SRV example advertises port 5061 for endpoint edge discovery. That is not trunk destination 5062 or 8934. [cite:1] [cite:4]

5h5d8ab, header July 13, 2026, says Webex Calling currently uses SRTP. Calling E2EE is opportunistic and disabled by default. Enable it under Services > Calling > Settings, Webex App tab, Security, “Enable end-end encryption when making calls.” It is not enabled for 1:1 PSTN calls, including between organizations, or for 1:1 premises trunks. A conference mixer drops it. Recording, auto attendant, voice portal, pre-answer early media, connected-line privacy, and an assistant answering for an executive prevent it. Call queue may allow it after an agent connects. Shared and virtual lines do not get it. Escalating to a meeting ends the Calling E2EE session. Zero-trust meetings are a different mechanism: MLS, up to 1000 participants, no PSTN or SIP devices, and no in-meeting AI Assistant or network recording. [cite:2]

nhvl4hw tells you to select the provider before enabling users, and it contains both default sentences. Webex retention is one year and 100 GB. Dubber Go is 30 days. Do not paste either number onto contact-center QM. [cite:3]

nvfbjts, header September 08, 2024, is the WxCC WebRTC procedure: Calling or the $0 PSTN add-on plus Contact Center, RedSky password at least 16 characters, buildings, alerts, wiremap, 933, then Enhanced emergency calling. RedSky access tests. Emergency call routing activates. The agent’s identification type is Device User Id equal to the email. b2exve, revision line February 23, 2026 and still present on the October 14 retrieval, names the RedSky hosts on port 443. [cite:4] [cite:5]

04 · Ecosystem

Ecosystem and sister technologies

TLS 1.2 and 1.3
The SIP security article’s supported TLS versions for secure SIP. [cite:1]
SRTP suite
AES_CM_128_HMAC_SHA1_80 is the SRTP key the same article lists for secure media. [cite:1]
Calling E2EE
Opportunistic. Disabled by default. Calls start on SRTP and upgrade when clients support it and nothing forces media processing. [cite:2]
end-end encryption toggle
The article’s hyphenation. Services > Calling > Settings > Webex App tab > Security. [cite:2]
Recording defeats E2EE
Call recording makes the service process media, so E2EE is disabled. [cite:2]
Webex recording provider
nhvl4hw says both “Webex is the default value” and “Dubber is chosen by default.” Quote both. Retention one year and 100 GB. [cite:3]
Dubber Go
30 days, with a user portal, in the same recording article. [cite:3]
RedSky
Emergency provider for Webex Calling and for WxCC WebRTC desktops. Hosts api.wxc.e911cloud.com and wxc.e911cloud.com, port 443. b2exve does not name TCP on that row. [cite:4] [cite:5]
933
nj0abhbb, header September 24, 2025, says United States and Canada locations dial 933 to test emergency-call email generation without alerting public safety personnel. That sentence is the Calling notification test. nvfbjts, header September 08, 2024, says place 933 calls, then activate Emergency call routing, and uses RedSky access to test location configuration. Read nvfbjts before you say whether that WxCC 933 call reaches a PSAP. The article does not say. re-check [cite:5] [cite:6]
Device User Id
For a contact-center agent in RedSky, the identification type must be Device User Id and it must equal the agent email. Then install myE911. [cite:5]
Kari and RAY BAUM
nvfbjts: direct 911, internal notification, and a dispatchable location for WebRTC desktops that have no traditional phone. [cite:5]
mTLS FQDN
The certificate CN or SAN must match the Control Hub FQDN. The article’s example strips :5061 off london.lgw.cisco.com. [cite:1]
Server Authentication EKU
Supported alone. Webex does not require Client Authentication EKU. Some third-party SBCs reject that certificate. [cite:1]
Edge SRV port 5061
The nslookup example in jwkbt2 advertises 5061 for endpoint discovery. Trunk destinations in the port reference are 5062 and 8934. Do not merge them. [cite:1] [cite:4]
Zero-trust meetings
MLS, up to 1000 participants. PSTN and SIP devices are not in those meetings. In-meeting AI Assistant, NBR, and transcription need decrypted media and are not in ZT meetings. Not the same switch as Calling E2EE. [cite:2]
Government cloud
Read the government port and crypto page on help.webex.com before you build an ACL. Commercial and government clouds publish different destinations, which is why this room keeps them apart.

05 · Flow

Decide in an order

  1. Confirm TLS 1.2 or 1.3 and AES_CM_128_HMAC_SHA1_80. [cite:1]
  2. Decide whether this call type is eligible. PSTN, premises trunk, conference, recording, auto attendant, voice portal, shared line, and virtual line are named exclusions. [cite:2]
  3. If the design requires a recording, say that E2EE is off because the service processes media. [cite:2]
  4. Choose a recording provider and quote both default sentences. [cite:3]
  5. For WebRTC agents, nvfbjts says test with 933 before Emergency call routing. That article’s header is September 08, 2024. re-check [cite:5] The agent article mwjlgk, header September 03, 2025, prints the MyE911 Cirrus host https://wxc.e911cloud.com and an email verification code. It does not reprint the password length, Device User Id, the $0 add-on, or 933-then-activate. [cite:7]
