00 · Header

T3 · Webex Contact Center

Agent Desktop & Supervisor

Agent Desktop is a browser. The sign-in article wants a display larger than 500 by 500 and zoom at 100 percent. The agent picks Desktop, Extension, or Dial Number, then a team. Supervisors listen and barge from the Interactions page. Those controls are gone from the Team Performance widget. A team is agents at a site, agent-based or capacity-based, and a skill profile is shared by at most 500 agents.

Room T3-R04 Version v0.1 last-verified: 2026-10-14 Difficulty L3 Est. time 80–100 min Prereq T3-R01, T3-R03 Reading 17 min

Key takeaways

  • Display larger than 500×500. Browser zoom 100%. One browser, one tab. Sign out from Idle, with no active conversation and no monitoring task. Desktop without browser permission, or a bad dial number, can RONA. If E911 was accepted and telephony still fails, share the Tracking ID. [cite:1]
  • Handle calls using Desktop (WebRTC), Extension, or Dial Number, depending on the profile. Digital-only users do not see telephony options. Auto sign-in is the “Don’t show this again” checkbox. A failed auto sign-in returns you to the preferences screen. An empty team selection still enables Save & Continue and then errors. [cite:1]
  • A team belongs to one site, and the site cannot be edited later. Agent-based teams list agents. Capacity-based teams take a dial number and a capacity, and you cannot switch the type afterward. Multimedia profile and the agent list are not for a capacity-based team. Queue ranking allows 50 queues across media types. [cite:2]
  • Only 500 agents can share one skill profile. Assign it on the agent or the team. Adding the agent to the team assigns the team’s skill profile. Skill changes do not require a new sign-in. Desktop layout is optional on an agent-based team. Team and layout edits are bidirectional in the audit log. New layout features appear after sign-in or a browser reload. [cite:2]

03 · Core concepts

What the desktop will and will not do

Telephony choice is the profile

Desktop means WebRTC in the browser. Headset control actions are not supported on those calls. Extension is a Webex Calling extension, prefilled when the profile has one. Dial Number is a Webex Calling number, with an international checkbox that builds +country and subscriber. [cite:1]

RONA is a sign-in symptom

The article says enhanced validation is there to stop RONA from an invalid or unassigned dial number or extension. Browser permission for Desktop is separate: the user is told to allow the microphone or talk to the administrator. E911 accepted and still no telephony is a Tracking ID case. [cite:1]

Listen moved

Monitoring and barge are only on the Interactions page. The Team Performance widget no longer has those controls. The Interactions article dates that behavior and also describes a granular agent-state toggle from April 30, 2026 through October 29, 2026. Keep that toggle off if you still need Webex WFO. [cite:3]

04 · Ecosystem & sister technologies

Glossary, map, sisters, edges

Glossary

Agent Desktop
The browser desktop. Display greater than 500×500. Zoom 100%. One browser and one tab. [cite:1]
WebRTC Desktop
Handle calls using Desktop. The browser is the phone. Headset control actions are not supported. [cite:1]
Dial Number
A Webex Calling number on the profile. International format uses the country-code checkbox. Other formats are E.164 or IDD. [cite:1]
Extension
A Webex Calling extension. One configured extension is prefilled. Several become a dropdown of pre-validated extensions. [cite:1]
Auto sign-in
Don’t show this again. Preferences are stored in the browser. A bad saved dial number sends you back to the preferences screen. [cite:1]
RONA
Redirect on no answer. The sign-in article ties it to missing browser permission and to an invalid dial number or extension, and to E911 accepted with telephony still down. [cite:1]
Team
Agents associated with one site. Parent site cannot be edited later. Active by default. Delete only when inactive. [cite:2]
Agent-based team
A listed set of agents. Optional desktop layout and multimedia profile. [cite:2]
Capacity-based team
Dial number and capacity. No named agent list and no multimedia profile. [cite:2]
Skill profile
Optional when skills-based routing is enabled. At most 500 agents share one. Team assignment copies the team’s profile onto the agent. Changes apply without a new sign-in. [cite:2]
Queue ranking
Optional per team, per media type. At most 50 queues across all media types. Unranked queues show None. [cite:2]
Desktop layout
Optional on an agent-based team. Users see new layout-based features after they sign in or reload. Team edits and layout edits show up together in the audit log. [cite:2]
Interactions page
Supervisor workspace: Active, Queued, and Completed. Listen and barge are here. [cite:3]
Listen
Monitor one agent from the interaction details. Answer the monitoring call. Pause mutes the supervisor’s audio. [cite:3]
Barge In
Join as a participant after listen. Not available during consult. [cite:3]
Granular agent state
Control Hub toggle available April 30, 2026 through October 29, 2026, then general availability. Leave it off to keep using Webex WFO. [cite:3]

06 · Config

Click paths

  1. Give the agent the desktop URL, a display above 500×500, and zoom 100%. Tell them to use one tab. [cite:1]
  2. If Azure SSO is enabled, the Microsoft Teams window does not appear. If it does, they can cancel and retry under Profile, Collaboration Tools, Try Again. [cite:1]
  3. Lock the dial number only if the administrator restricted it to the default DN. Otherwise the agent chooses Desktop, Extension, or Dial Number. Digital-only users skip telephony. [cite:1]
  4. Create the team at Services > Contact Center > User Management > Teams. Pick the site first. Choose agent-based or capacity-based. You cannot change that later. [cite:2]
  5. On an agent-based team, optionally set multimedia, desktop layout, and agents. Skill profile is optional when the feature is on, and only 500 agents share one. [cite:2]
  6. Rank queues only if you need it. Maximum 50 across telephony, chat, email, and social. Same rank may repeat. Save, then Create. [cite:2]
  7. Deactivate before delete. Inactive is the only deletable state. [cite:2]
  8. Supervisor: Interactions, Active, View, Listen, answer. Barge only after that. End Listen before sign-out. [cite:3]
  9. Through October 29, 2026, leave the granular agent-state toggle off when Webex WFO must keep working. [cite:3]
  10. Export or filter from Interactions if you need a list. The first paint is 500 interactions. History filters go out 13 months. [cite:3]

From Idle, with no active conversation and no monitoring task. [cite:1]

Desktop, Extension, and Dial Number, when the profile includes them. Digital-only users do not see them. [cite:1]

13 · Interview

Oral answers

30 seconds. The agent signs in through a browser, picks Desktop, an extension, or a dial number, and must pick a team. Sign-out is from Idle. Supervisors listen on the Interactions page, one agent at a time, and barge only after listen.

2 minutes. I would check zoom and the 500-pixel floor before I call it a bug. RONA on Desktop is often the microphone permission or an E911 case that needs a Tracking ID. RONA on a number is an invalid or unassigned DN. Teams are agent-based or capacity-based, the site and the type stick, and 500 agents share a skill profile. Ranking stops at 50 queues. Layout changes show up after a reload, and the audit log ties team edits to layout edits.

30 seconds, barge. Barge is a participant join. I cannot transfer, drop the agent, or start a consult while I am in it. Consult blocks barge. A transfer to another team or queue ends the monitor.

2 minutes, WFO and CRM. Through October 29, 2026 I leave the granular agent-state toggle off if Webex WFO is required. Chat and email are not on the CRM connectors, so a missing chat panel inside Salesforce is expected. Finesse gadgets are not this desktop; that crosswalk is marked in T6-R04.

What you will not say. You will not tell someone to listen from Team Performance. You will not require a re-login for a skill-profile change.
