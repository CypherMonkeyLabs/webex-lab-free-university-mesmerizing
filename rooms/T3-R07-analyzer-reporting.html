Analyzer & Reporting

T3-R07. Real-time visualizations, historical sessions, the desktop widget’s different clock, stock paths, and the AI Assistant reports that land in Analyzer. Retrieved 2026-10-14.

Reading 11 minDraftStudy notes

Key takeaways

  • Analyzer real-time reports stay up and default to a 5-second refresh (5–60). [cite:1]
  • Historical Analyzer reports stay active 8 hours. [cite:1]
  • The agent-statistics widget updates history every 24 hours and real-time every 60 seconds. [cite:2]
  • Threshold alerts auto-refresh every 3 minutes. [cite:1]

01 · TL;DR

Two products, four clocks

  • Analyzer real-time reports stay up and default to a 5-second refresh (5–60). [cite:1]
  • Historical Analyzer reports stay active 8 hours. [cite:1]
  • The agent-statistics widget updates history every 24 hours and real-time every 60 seconds. [cite:2]
  • Threshold alerts auto-refresh every 3 minutes. [cite:1]
  • Sudden Disconnected Count is not populated. [cite:3]

03 · Core

What the user guide actually separates

Real-time reports remain available indefinitely, as the data refreshes automatically. Historical reports stay active for 8 hours. After that you may need to re-authenticate, but visible data does not expire if the report is not scrolled or reloaded. [cite:1]

While a real-time report runs, the Refresh drop-down offers 5 to 60 seconds in increments of 5. New reports default to 5 seconds. Existing reports that were under 5 seconds move to 5. If a refresh hits while you are filtering, the guide says the checkboxes can all become selected; wait, then close and reopen the filter. [cite:1]

You cannot run a visualization with a long duration and a short interval. Reset both. tajemk prints more than one Duration list, and this room does not collapse them. The Details tab lists None, 5, 15, or 30 minutes, and Start of Day. Create a Visualization’s realtime Compute table also lists 10 minutes and Custom, looking back up to 14 days. The Supported Intervals table names Today, Yesterday, This Week, Last Week, Last 7 days, This Month, Last Month, This Year, and Custom. Blank interval cells in that table are not filled in here. Historical Alerts uses another list: Yesterday, This Week, Last Week, Last 7 Days, This Month, Last Month, This Year, and Custom, and a custom start date within three years. The 10-minute and Custom gap between the Details tab and the create table is re-check. The 2026-10-14 extract had no header date. [cite:1]

Stock reports are read-only under Visualizations. One path in the stock article is Stock Reports > Historical Reports > Agent Reports. The same article repeats that Sudden Disconnected Count is not used and will not be populated. [cite:3]

The desktop agent-statistics widget is a second clock. Historical updates every 24 hours. Real-time updates every 60 seconds. Launch opens Analyzer from the Agent Stats Chart Realtime or Detailed Summary widget. [cite:2]

04 · Ecosystem

Ecosystem and sister technologies

Analyzer is the contact-center reporter. Calling CDR, CUIC, and the Search API are neighbors, not aliases.

Analyzer
The Webex Contact Center reporting application. It mines real-time and historical data and shows visualizations, dashboards, and folders on one home page. [cite:1]
Visualization
The report object you run. Stock reports live under Visualizations and are read-only. [cite:1]
Real-time report
Stays available indefinitely because the data refreshes automatically. A new real-time report defaults to a 5-second refresh. The Refresh drop-down runs from 5 to 60 seconds in steps of 5. [cite:1]
Historical report
Stays active for 8 hours. After that you may need to re-authenticate for the latest updates. Visible data does not expire if you do not scroll or reload. [cite:1]
Real-time alert
The Threshold Alerts window. Auto-refresh is every 3 minutes unless you stop it. [cite:1]
Agent statistics widget
The desktop widget. Its historical report updates every 24 hours. Its real-time report updates every 60 seconds. That is not the Analyzer visualization refresh. [cite:2]
Stock report path
Example: Stock Reports > Historical Reports > Agent Reports. Agent Statistics is a table on that path. [cite:3]
Sudden Disconnected Count
A field the stock-report article says is not used and will not be populated. Do not coach agents from a zero in that column. [cite:3]
Export
Historical visualizations can export Excel or CSV. Real-time and compound visualizations cannot. A drill-down with real-time data cannot. [cite:1]
Auto CSAT report
An AI Assistant report. One row per agent, with average, minimum, and maximum predicted scores, also sliced by team and queue in the article’s questions. [cite:4]
Topic Analytics
Trending Topics and Topic Summary reports for contact drivers. [cite:4]
Agent Wellness Breaks
The Analyzer report for wellness breaks given to agents. [cite:4]
KPI latency
Supervisor Desktop KPI cards are push-based. Analyzer is pull-based: the UI requests data. [cite:5]
Search API
A different historical door. 36-month and 365-day windows are in T3-R01. Do not call that window an Analyzer refresh rate.
CUIC
The Enterprise reporter. Post-upgrade cleanup in a WxCC 1.0 move exposes legacy Analyzer data. It does not convert CUIC. The CUIC row stays marked in T6-R04.
Duration field
tajemk says a visualization has Duration and Interval, and that a long duration with a short interval cannot run. The enumerated duration labels are not copied into this glossary.

Ecosystem trouble

A zero in Sudden Disconnected Count is the article’s unused field, not an outage. A missing Auto CSAT report is an add-on or a toggle, not a broken queue.

05 · Flow

Read a number without mixing clocks

  1. Name the surface: Analyzer visualization, desktop widget, or Supervisor KPI card.
  2. If it is Analyzer, say real-time or historical before you say a refresh.
  3. If someone says 60 seconds, ask whether they launched the agent-statistics widget.
  4. If they need a file, use a historical visualization.
  5. If the column is Sudden Disconnected Count, stop.

06 · Config

Paths you can click from the articles

  • Stock reports: Visualizations. [cite:1]
  • Agent Statistics: Stock Reports > Historical Reports > Agent Reports. [cite:3]
  • Alerts: Threshold Alerts icon. Stop or Start Auto Refresh. [cite:1]
  • Desktop: Launch on Agent Stats Chart Realtime or Detailed Summary. [cite:2]
  • AI Assistant reports named in ioqbvd, including Agent Wellness Breaks and Auto CSAT under the article’s report sections. [cite:4]
  • AI Assistant itself is enabled in Control Hub. The desktop icon is nvvv1zb, taught in T8-R05.

09 · Self-question

Oral ladder

L1Where do stock reports live?

Under Visualizations. They are read-only. [cite:1]

L2How long does a real-time report stay open?

Indefinitely, because it refreshes. [cite:1]

L3How long does a historical report stay active?

8 hours, then you may need to re-authenticate. Visible rows do not expire if you do not scroll or reload. [cite:1]

L4What refresh can you pick on a new real-time visualization?

5 to 60 seconds, step 5, default 5. Older reports under 5 seconds move to 5. [cite:1]

L5What does the agent-statistics widget do?

Historical every 24 hours. Real-time every 60 seconds. [cite:2]

L6Name one stock path.

Stock Reports > Historical Reports > Agent Reports. [cite:3]

L7Why is Sudden Disconnected Count empty?

The article says the field is not used and will not be populated. [cite:3]

L8What can you export?

Historical visualizations, Excel or CSV. Not real-time. Not compound. [cite:1]

L9How often do threshold alerts refresh?

Every 3 minutes, unless you stop auto-refresh. [cite:1]

L10Which AI Assistant reports does ioqbvd name?

Agent Wellness Breaks, Auto CSAT, Dropped Call Summaries, Agent Summary, Real-time Transcriptions, Topic Analytics, Real-Time Assist KPIs. [cite:4]

L11Why can Supervisor Desktop and Analyzer disagree on freshness?

Desktop cards are push. Analyzer is pull. [cite:5]

L12Does cleanup convert CUIC?

No. WxCC 1.0 cleanup exposes legacy Analyzer data. CUIC stays marked in T6-R04.

A new real-time Analyzer report refreshes every:

A new real-time Analyzer report refreshes every: 5 seconds by default. You can choose 5 to 60 in steps of 5. The 60-second clock is the desktop agent-statistics widget. [cite:1] [cite:2]

Historical Analyzer sessions stay active for:

Answer

Historical Analyzer sessions stay active for: 8 hours. [cite:1]

Answer

Stock Reports > Historical Reports > Agent Reports. [cite:3]

Answer

Sudden Disconnected Count shows zero. You: Leave it. The field is not populated. [cite:3]

Q6Scenario

Threshold alerts sit still for ten minutes.

Answer

Check Stop Auto Refresh. The default is 3 minutes. [cite:1]

Q9Scenario

Someone sizes a wallboard from the 24-hour widget.

Someone sizes a wallboard from the 24-hour widget.: That interval is the desktop historical agent statistics, not an Analyzer visualization default. [cite:2]

Q10Draw it

Draw two clocks.

Answer

Two products. Analyzer real-time reports default to 5 seconds, and a historical Analyzer session stays active 8 hours. The agent-statistics widget updates real-time every 60 seconds and history every 24 hours. [cite:1] [cite:2]

Q11Oral

Answer

What does pull-based mean here: The Analyzer UI requests data. Supervisor Desktop publishes events as they happen. [cite:5]
