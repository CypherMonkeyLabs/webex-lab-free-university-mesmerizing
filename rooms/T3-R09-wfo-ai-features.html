01 · TL;DR

Two add-ons, two scopes, one place they are not

  • The Control Hub path is Services > Contact Center, then AI Features under Desktop Experience. [cite:1]
  • Sentiment analysis requires real-time transcription on those queues, and flows that start transcription. [cite:1]
  • Auto CSAT requires call recording for post-call processing. [cite:1]
  • For every queue, real-time transcription adds Start Media Stream directly after the AgentAnswered event. [cite:1]
  • Basic QM’s existing-package column adds items Basic QM does not list, including live screen monitoring. [cite:2]
Why it matters. A design that turns on Auto CSAT without recording, or that orders an Enterprise WFO SKU because a multi-tenant article mentioned workforce, will not match these pages.

03 · Core

Read the scope column before you click Save

6m6r3fb says customers purchase the AI Quality Management add-on A-FLEX-AI-QM or the bundle A-FLEX-AI-QMMB. Users need AI Assistant in the desktop-experience section of the user profile. Header July 24, 2026. [cite:1]

The feature table’s enablement scopes are: Evaluation and Speech Analytics, organization; Coaching Insights, organization; Sentiment analysis, queue; Auto CSAT, agent; Real-time transcriptions, queue. Sentiment, Auto CSAT, and real-time transcription are also part of the AI Assistant SKU. The bundle unlocks AI Assistant features on the same Control Hub page. [cite:1]

Auto CSAT’s two sentences

The table says Auto CSAT’s enablement scope is Agent. The how-to turns Auto CSAT on from Queue level settings, for all queues or selected queues, and then chooses Experience Management survey questions or a global variable. Call recording must be enabled for the post-call processing that produces the predictions. Do not collapse the scope cell and the click path. [cite:1]

Transcription is a flow edit

For all queues, add Start Media Stream on the event flow immediately after AgentAnswered, then save and publish. Specific queues use the conditional media-streaming article instead. Global layouts show transcription without a JSON edit. Custom layouts need visibility RT_TRANSCRIPT for agent, supervisor, and agent-supervisor, and the AI Assistant component is the advancedHeader item comp ai-assistant. [cite:1]

Sentiment is positive, neutral, or negative for completed interactions. Before you enable it, real-time transcription must be on for those queues and the flows must start transcription. The sentiment steps also say you can apply it to all queues or pick queues and summary types. [cite:1]

nmzg380, header August 13, 2025, introduces Basic WFM and Basic QM for Webex WFO on Webex Contact Center. Basic WFM names forecasting across voice, digital, and back-office, MyTime, shift bidding, multi-skill scheduling, long-term staff budgeting, intraday management, real-time adherence, a mobile app, standard reporting, gamification, schedule-change notifications, and meetings or offline activities. Basic QM names call recording, evaluation across voice and digital, playback and delete, text search, contact-details export, screen recording, evaluation forms, standard evaluation viewing, and contact import. The existing QM column adds, among other items, live screen monitoring, evaluation calibration, and evaluation appeal, which means those are not in the Basic column. re-check [cite:2]

nmzg380 says you order with the relevant Basic WFM and Basic QM SKUs and points at the Cisco ordering guides. It does not print the A-FLEX-WFO enterprise strings. Those strings stay on py6u9h until that page is re-read. TODO-verify [cite:2]
