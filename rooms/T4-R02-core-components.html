00 · Header

Core Components

T4-R02. The four major components in the Unified CCE 15.0(1) Product Architecture chapter: Router, Logger, Peripheral Gateway, and Administration & Data Server, plus Unified Intelligence Center. Updated April 30, 2025. This is the component guide the Enterprise overview points at. It is not a cloud Webex CCE data-sheet inventory.

Reading 16 minv0.1last-verified: TODOL3DraftStudy notes

Key takeaways

  • The chapter names four major components: Router, Logger, Peripheral Gateway, and Administration & Data Server. [cite:1]
  • Side A Router talks only to the Side A Logger. Both router sides stay in service together and use MDS to lock step. [cite:1]
  • The Unified CM PIM is active on one side. OPC is the lock-step process. VRU PIM uses GED-125. [cite:1]
  • Unified Intelligence Center is a publisher plus up to seven subscribers, eight nodes maximum. The standard data source is an AW-HDS. [cite:1]

Prereq rooms: T4-R01 for the product-name boundary. Call flow is T4-R03. Script nodes are T4-R04.

  • A Router plus Logger on one server is a Central Controller. [cite:1]
  • PGs are duplex, but for many PG parts only one side is active. [cite:1]

03 · Core

Duplex does not mean both sides are active everywhere

The Product Architecture chapter of the Serviceability Guide for Unified CCE Release 15.0(1), updated April 30, 2025, says Unified CCE delivers intelligent contact routing, call treatment, network-to-desktop CTI, and multichannel contact management. It was derived from Unified ICME. The primary difference stated there is that Unified CCE integrates only with the Cisco Unified Communications Manager IP PBX. There is no single-server implementation. re-check [cite:1]

Four major components: the Router makes routing decisions and selects a peripheral or agent for a voice call, email, chat, and so on. The Logger stores and replicates configuration, real-time, and historical data. The Peripheral Gateway is the gateway to a peripheral such as an IP PBX or a VRU, and a CTI gateway toward desktops. The Administration & Data Server provides configuration from the Logger, real-time data, a platform for the Historical Data Server, and the interface for Script Editor and Internet Script Editor. [cite:1]

Central Controller

Routers are duplex. Side A and Side B use MDS so both sides have the same data and both stay in service. Loggers are duplex and tightly coupled. Side A Router sends messages only to the Side A Logger. After an outage, loggers resynchronize with a bulk copy. A co-located Router and Logger is the Central Controller. [cite:1]

PG active side is not the router model

PG messages to OPC go through MDS so the two sides lock step, but for many PG components only one side is active. The PIM is not lock-step. Either the Side A or Side B PIM is active for each peripheral. OPC is the critical lock-step process and is primary for agent state when the peripheral is Unified CM, because Unified CM knows lines, not agent state. An ACD PG mirrors agent state that the ACD already tracks. [cite:1]

Administration & Data Server types in the chapter: AW with configuration and real-time and no historical data; AW-HDS-DDS with configuration, real-time, historical, and call detail; AW-HDS with configuration, real-time, and historical data but no call detail. The HDS is optional on an AW and is the long-term store. Historical data replicates from the Logger to one or more HDS databases. The Logger configuration database is authoritative. [cite:1]

Unified Intelligence Center is the web reporting platform for Unified ICME and Unified CCE. You install it standalone or in a cluster of at most eight nodes: one publisher, called the Controller, and up to seven subscribers, called Members. The Controller includes a Member, so a Controller-only deployment is valid. Reporting runs on Members. Administration runs on the Controller. The standard Unified CCE deployment uses the AW-HDS as the data source, and the chapter also allows the CVP Reporting Server as a data source. Stock report templates for Unified CCE data are preinstalled. Grid reports export to Microsoft Excel. [cite:1]

This room teaches the Unified CCE chapter, and it does not move those names onto the multi-tenant product. [cite:1] [cite:2]

04 · Ecosystem

Ecosystem and sister technologies

These components are Unified CCE 15.0(1). Multi-tenant Webex Contact Center does not use this drawing.

Router
Runs the script and picks the target. Both sides stay in service. [cite:1]
Logger
First store for historical data, and the authoritative configuration database. [cite:1]
Central Controller
Router and Logger, often co-located. [cite:1]
MDS
Message Delivery Service. Feeds both sides the same messages in the same order. [cite:1]
PG
Normalizes the peripheral and tracks agent or task state. [cite:1]
PIM
Peripheral Interface Manager. One side active. Not lock-step. [cite:1]
OPC
Open Peripheral Controller. Lock-step. Primary agent state for a Unified CM PG. [cite:1]
GED-125
VRU PIM protocol. [cite:1]
GED-188
CTI Server protocol. Direct desktop use is deprecated in this chapter. [cite:1]
AW-HDS
Configuration, real-time, and historical data, no call detail. CUIC’s standard source. [cite:1]
CUIC Controller
The mandatory publisher. Includes a Member. Administration runs here. [cite:1]
