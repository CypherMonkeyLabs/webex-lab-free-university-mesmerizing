03 · Core concepts

What the index is allowed to say

Four components

Router, Logger, Peripheral Gateway, and Administration & Data Server. The Router makes the routing decision. The Logger stores configuration, real-time, and historical data. The PG normalizes the peripheral. The Administration & Data Server provides configuration from the Logger, a real-time interface, and the historical data server platform, and it offers Script Editor and Internet Script Editor. [cite:1] re-check

Lock-step is not every process

MDS delivers the same messages in the same order to duplex processes that hold centralized state. Both Router sides are concurrently in service. OPC on the PG is kept in lock-step. The PIM is not a lock-step process and does not share data between sides. Either the Side A or the Side B PIM is active for each peripheral. [cite:1]

Logger recovery is Logger to Logger

Side A Router sends messages only to the Side A Logger. Side B Router sends messages only to the Side B Logger. Because the Routers run in lock-step, those messages match while they are flowing. Recovery between Loggers uses bulk database copy. [cite:1]

04 · Ecosystem

Where the index stops

Glossary

Router
Selects a peripheral or agent for an inbound contact. Both sides stay in service and share data through MDS. [cite:1]
Logger
Stores configuration, real-time, and historical data. Hears only its own Router. [cite:1]
Central Controller
A Router and Logger combination. Often collocated on one server. [cite:1]
PG
Talks to the telephony device, tracks agent and call state, and forwards routing requests. Duplexed with MDS, with one side active for many components. [cite:1]
PIM
Peripheral Interface Manager. Not lock-step. One side is active per peripheral. [cite:1]
OPC
Open Peripheral Controller. Critical PG process. Kept in lock-step with the other side. [cite:1]
Administration & Data Server
Configuration copy, real-time interface, historical data server platform, and the Script Editor interface. [cite:1]
HDS
Optional Historical Data Server. Long-term repository. Offloads historical reporting from the Logger. [cite:1]
SendToVRU
ICM Script Editor node that connects the call to the Network VRU. [cite:2]
VRU PG and MR PG
These PGs do not maintain agent state. They maintain call or task state and expose an interface for instructions from the Router. [cite:1]

09 · Self-question

Twelve rungs

L0Which four components does the serviceability chapter call major?

Router, Logger, Peripheral Gateway, and Administration & Data Server. [cite:1]

L1Are both Router sides in service at once?

Yes. They stay in lock-step through MDS and both are concurrently in service. [cite:1]

L1Which Logger does Side B Router talk to?

Only the Side B Logger. [cite:1]

L2What is a Central Controller?

A Router and Logger combination, often on the same server. [cite:1]

L2Which PG process is lock-step, and which is not?

OPC is lock-step. The PIM is not. One PIM side is active per peripheral. [cite:1]

L2What does a VRU PG maintain?

Call state, not agent state. An MR PG maintains task state. [cite:1]

L3Where is the authoritative configuration database?

On the Logger. ADS databases are copies. [cite:1]

L3What does SendToVRU do, in the sentence the CVP guide gives?

It connects the call to the Network VRU. [cite:2]

L3Why is Unified CM agent state different from ACD agent state?

Unified CM knows lines. The PG is primary for agent state. An ACD PG mirrors the ACD. [cite:1]

L4How does a configuration change reach the Logger?

ADS client to DBAgent, DBAgent to Router through MDS, Router validates and sends it to the Logger, Logger confirms, Router distributes to clients. [cite:1]

L4Which Canon room owns the 2,000-user Finesse line?

T4-R08, from the design-guide high-availability chapter. This index does not merge it with 24,000 or 48,000. [cite:3]

L5What would you need before you write a session-by-session map?

13 · Interview

Oral answers

30 seconds. Unified CCE’s serviceability chapter names four major components: Router, Logger, PG, and Administration & Data Server. Both Routers stay in service. Each Logger listens only to its own Router.

2 minutes. MDS keeps duplex state processes on the same messages in the same order. OPC is one of those processes. The PIM is not. One PIM side is active per peripheral, and the other side activates if the connection drops. A Unified CM PG is primary for agent state because Unified CM tracks lines. A VRU PG tracks calls, not agents. Configuration changes go through DBAgent and the Router, and the Logger database is the authoritative copy. Historical reporting can move to an HDS.

30 seconds, the index. I map T4 topics to those chapters. I do not invent a classroom session number. SendToVRU is a named Script Editor node. The rest of a scripting course stays TODO-verify.

2 minutes, the boundaries. Webex Contact Center Enterprise as a cloud offer is a help article, not a replacement for this chapter. Flow Designer is a different product’s flow tool. The 500-to-24,000 quick-deployment range, the Finesse 2,000 line, and the 48,000 what’s-new sentence stay in their own rooms. The architecture chapter I am quoting was updated April 30, 2025, so it stays re-check.

What you will not say. You will not quote a class date, a session number, or a personal biography.
