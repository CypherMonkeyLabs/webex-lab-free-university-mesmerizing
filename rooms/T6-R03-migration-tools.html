00 · Header

T6 · Migrations

Migration Tools

Cisco documents three ways onto multi-tenant Webex Calling: Control Hub tools, certified migration providers, and Webex Setup Assist. The Control Hub user tool moves at most 1,000 users and 1,000 devices in one task. The feature tool does not currently build call park or call pickup. A Python script does.

Room T6-R03 Version v0.1 last-verified: TODO Difficulty L3 Est. time 90–110 min Prereq T6-R02 Reading 17 min

Key takeaways

  • December 2025 deployment guide: Webex Migration Tools, Certified Migration Providers, and Webex Setup Assist. [cite:1]
  • One Unified CM migration task: at most 1,000 users and 1,000 devices. Task name at least 8 characters. [cite:2]
  • That user tool assigns Calling professional or CX Essentials. It does not assign a Standard license. [cite:2]
  • Feature migration maps auto attendant, devices, lines, layout, virtual line, call queue, hunt group, call park, and user calling data. The tool does not currently support call park and call pickup CSVs. The Python script creates those two files. [cite:3]
  • Firmware migration steps apply to Dedicated Instance. 8821 and 8831 are not eligible. [cite:4]

01 · Executive summary

Five lines, then why it matters

  • Migration Insights can run from any organization. You do not need the destination customer org to upload a Unified CM tar. [cite:2]
  • Use SharedlineGroupMigrationReport.csv and HuntGroup_CallQueue_CallPark_CallPickUpGroups.csv to see who must move together. [cite:2]
  • A-FLEX-P-CALL is the entitlement the user-migration article names for temporary licensing from GLO, up to 18 months. [cite:2]
  • Feature-tool upload limits: Unified CM tar 350 MB, Unity call-handler zip 2 GB. [cite:3]
  • The Dedicated Instance pre-migration assistant is a different tile. It does not perform that migration. T5-R06. [cite:5]
Why it matters. Tool choice fails when a Standard license is forced through the user task, when call pickup is expected from the feature tool alone, or when an 8821 is put on the MPP list.

03 · Core concepts

Which tile does which job

Three families

The December 2025 deployment guide names Webex Migration Tools as self-service tools in Control Hub, Certified Migration Providers as validated software for complex and large migrations, and Webex Setup Assist as a Cisco-led service. [cite:1]

License the user tool will not assign

Users migrated with the Unified CM user tool can only be assigned Calling professional or CX Essentials. To assign a Webex Standard license, do not use this tool. Use a user CSV, then the feature tool for the rest. Workspaces can be Workspace or Professional Workspace. [cite:2]

Park and pickup

The feature article lists Call Park among mapped data, and the script section says the feature tool does not currently support CallPark.csv and CallPickupgroup.csv. The script UserBasedUCMFeatureMigration creates those files from CDR. Keep both sentences. [cite:3]

Dedicated Instance

The user-migration article and the firmware article each say the steps apply to Dedicated Instance. The pre-migration assistant is still a different tile and does not perform the Dedicated Instance migration. [cite:2] [cite:4] [cite:5]

06 · Config

Clicks the articles name

  1. Open Services → Upgrades and Migrations. Run Migration Insights on the tar before you build batches. [cite:2]
  2. On Migrate Unified CM to Webex Calling, finish prerequisites, import the tar, and start a task only after the tar upload enables the button. [cite:2]
  3. Map each device pool to a location or leave it undefined. Resolve a device that is tied to more than one location. Other warnings, including extension length, are informational. [cite:2]
  4. Choose numbers by PSTN type. Do not expect Auto assign on an all-local-gateway task, or Add numbers on an all-cloud-PSTN task. [cite:2]
  5. Set professional or CX Essentials. Stop if the requirement is Standard. [cite:2]
  6. Prepare to migrate, then Complete migration. On Unified CM, upload the CSV as Phone / Update Phone - Custom File, and run or schedule the job. [cite:2]
  7. For features, open Services → Updates and Migrations → Migrate features from UCM. Stay under 350 MB for the tar and 2 GB for the Unity zip. [cite:3]
  8. Run UserBasedUCMFeatureMigration when you need park or pickup files. Keep 8821 and 8831 out of the firmware tool. [cite:3] [cite:4]

13 · Interview

Oral answers

30 seconds. The December 2025 guide gives you Control Hub tools, certified providers, and Setup Assist. The self-service user task takes a Unified CM tar, 1,000 users and 1,000 devices at a time, and it will not assign a Standard license.

2 minutes. Insights can run in any org and tells you who shares lines and group features. The user task maps device pools to locations, then returns a manifest you load with Update Phone - Custom File. If Cloud-Connected UC is on, it takes the device migration. The feature tool maps queues, hunts, auto attendants, and the rest of its list, with a 350 MB tar and a 2 GB Unity zip. It does not currently emit park and pickup CSVs. The Python script UserBasedUCMFeatureMigration does, from CDR. Quote the overview’s “call park” mapping and that script sentence together.

30 seconds, phones. 8821 and 8831 do not migrate to MPP. 8832NR can, with limitations. V15 and later hardware needs 11.3.3 MPP and cannot downgrade. Those firmware steps also apply to Dedicated Instance.

2 minutes, the other tile. Dedicated Instance has its own pre-migration assistant. It does not perform the migration. Do not paste the 1,000-user cap onto that scheduler. A-FLEX-P-CALL is the temporary entitlement the user-migration article names, for up to 18 months, through GLO. A third-party PBX is not this tar.

What you will not say. You will not say the feature tool builds pickup by itself. You will not put an 8821 on the MPP list. You will not invent an Avaya import button.
