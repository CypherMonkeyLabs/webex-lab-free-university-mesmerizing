T7 · SIP, routing, and queues

CUBE deep dive

Dial-peer translation, the G.711 codec class, and the high-CPU signature. Sample passwords from jr1i3r are not here. Retrieved 2026-10-14.

Room T7-R02 Version v0.1 last-verified: TODO Difficulty L4 Est. time 110–140 min Prereq T7-R01 Reading 18 min

Key takeaways

  • jr1i3r’s voice class codec 100 allows G.711 only: preference 1 g711ulaw, preference 2 g711alaw. Add another codec only when both sides support it. DSP transcoding is supported and is not in that guide. [cite:1]
  • A voice translation profile is applied on a dial-peer as translation-profile incoming or translation-profile outgoing. The profile can translate called, calling, and redirect-called. 64020 says redirect-called is the redirect DNIS, or the original called number. [cite:2]
  • Test with test voice translation-rule before the profile is on a live peer. The 64020 example is Router#test voice translation-rule 1 5551234. [cite:2]
  • The CUBE dial-peer guide matches a SIP inbound leg on URI classes before incoming called-number and answer-address. Document 211306 is the longer inbound list. This room does not merge the two lists. [cite:3]
  • DS 64224 disables all debugs and uninstalls diagnostic signatures when CPU is at 75 percent or more. The article’s FTP URL contains a sample username and password. Those credentials are not copied here. [cite:1]

03 · Core concepts

Translation profiles and the codec class

Called number changes on the outbound peer

64020 puts translation-profile outgoing on the dial-peer that sends the call. translation-profile incoming applies to the inbound VoIP call. [cite:2]

Thirty-one characters

The same guide says the size of translation-profile incoming is thirty-one characters. A long profile name will not fit that field. [cite:2]

Do not paste a carrier PDF into every router

Cisco’s Lumen Local Gateway PDF prints translation rules for that carrier example, including patterns aimed at Webex Calling and at the PSTN. Those rules are the example. Read them as an illustration of where a profile sits, not as this customer’s dial plan. [cite:4]

ICE is a stun class, not a codec

jr1i3r configures voice class stun-usage 100 to enable ICE on the Webex Calling trunk, separate from the codec class. [cite:1]

04 · Ecosystem & sister technologies

Glossary, map, sisters, edges

Glossary

voice class codec 100
jr1i3r’s filter. Preference 1 is g711ulaw. Preference 2 is g711alaw. [cite:1]
Additional codec
The article allows more types when both the originating and terminating systems support them. [cite:1]
DSP transcoding
Supported for more complex designs. Not included in the Local Gateway guide. [cite:1]
voice translation-rule
Global rule set. 64020 defines it before the profile. [cite:2]
voice translation-profile
Binds a translation rule with translate called, translate calling, or translate redirect-called. 64020 says redirect-called is the redirect DNIS, or the original called number. [cite:2]
translation-profile incoming
Number translation for an incoming VoIP call. Name length in that table is thirty-one characters. [cite:2]
translation-profile outgoing
Number translation for the outbound call. [cite:2]
translate called
The profile command that selects the rule for the called number. [cite:2]
translate calling
The profile command for the calling number. [cite:2]
test voice translation-rule
The exec command 64020 prints. Example input 5551234 against rule 1. [cite:2]
call-block translation-profile
A profile used to decide which inbound calls to reject. [cite:2]
URI before called-number
The CUBE dial-peer chapter lists URI class matches ahead of incoming called-number. [cite:3]
211306
The IOS call-routing support document. T7-R01 quotes its full inbound order. This room does not shorten that order to the CUBE chapter’s list. [cite:3]
stun-usage 100
jr1i3r’s ICE class on the Webex trunk. [cite:1]
DS 64224
High-CPU signature. At 75 percent it disables debugs and uninstalls diagnostic signatures. [cite:1]
Sample secret
The DS install steps show an FTP URL with a username and password. This Canon does not store that sample. [cite:1]

06 · Config

Lines, without sample passwords

  1. Create voice class codec 100 exactly as jr1i3r prints it before you add codecs. [cite:1]
  2. Create the translation rule and run test voice translation-rule. [cite:2]
  3. Create the profile. Keep the name inside thirty-one characters. Apply incoming or outgoing on the peer that needs it. [cite:2]
  4. Read the CUBE dial-peer inbound order, then read 211306 before you tell someone called-number is first. [cite:3]
  5. Install DS 64224 from the Diagnostic Signatures Lookup Tool steps in jr1i3r. Omit the sample FTP credentials. [cite:1]
