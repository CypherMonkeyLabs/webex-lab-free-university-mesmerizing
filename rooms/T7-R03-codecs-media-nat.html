T7 · SIP, routing, and queues

Codecs, media, and NAT

Media optimization, the G.711 class, and the port reference. SIP ALG is a recommendation on b2exve whose revision line is January 21, 2025, so that sentence stays re-check. Retrieved 2026-10-14.

Room T7-R03 Version v0.1 last-verified: TODO Difficulty L3 Est. time 100–130 min Prereq T7-R02 Reading 17 min

Key takeaways

  • Media optimization uses ICE. Desk phones except DECT and ATA, the Webex App, and Local Gateway are the supported set. It is on by default for desk phones and the Webex App. [cite:1]
  • Local Gateway uses ICE-lite. Minimum CUBE software in that article is 17.3 or 16.12.5. The gateway needs a public address or same-network reachability. Interorganization calls send media through the PSTN. [cite:1]
  • If call recording is enabled, recorded-call media goes to the cloud and is not optimized. ICE and recording each add a small initial audio delay. Together the delay is longer. [cite:1]
  • jr1i3r’s codec class is g711ulaw then g711alaw. b2exve, retrieved 2026-10-14, puts successful ICE media for the Webex App on 8500–8699 and for devices on 19560–19661. [cite:2] [cite:3]
  • b2exve recommends turning SIP ALG off. The revision history dates that addition at January 21, 2025. re-check [cite:3]

03 · Core concepts

Four ICE phases, then the port table

Four phases

nt6eyxb: candidate discovery, candidate exchange over SIP, connectivity checks, then media path optimization with a reinvite. The server-reflexive address comes from a STUN server in the Webex Calling cloud. [cite:1]

Recording defeats the shortcut

The same article says recorded media is routed to the cloud and is not optimized. [cite:1]

Signaling still needs the internet

To route calls, signaling goes to the Webex Calling cloud. An active internet connection is always required. Media is most of the traffic. [cite:1]

ALG and NAT pools are different sentences

August 13, 2026 on b2exve: validate NAT pool size so PAT does not exhaust ports. The SIP ALG recommendation is the January 21, 2025 addition. Keep those dates apart. [cite:3]

04 · Ecosystem & sister technologies

Glossary, map, sisters, edges

Glossary

ICE
Interactive Connectivity Establishment. The method nt6eyxb uses to find a direct media path. [cite:1]
ICE-lite
What CUBE supports. The article points at further restrictions on CUBE and does not paste them into the Webex page. [cite:1]
STUN
Session Traversal Utilities for NAT. Used to learn a server-reflexive address. [cite:1]
Candidate
A local address or a server-reflexive address where the endpoint can receive media. [cite:1]
Reinvite
The SIP request that starts media on the optimized path after checks succeed. [cite:1]
Default on
Desk phones and Webex App. DECT and ATA are excluded. [cite:1]
Local Gateway command
The article’s words are “STUN usage lite,” reviewed in the Local Gateway registration article. jr1i3r prints voice class stun-usage 100. [cite:1] [cite:2]
CUBE minimum for this feature
17.3 or 16.12.5, in nt6eyxb. That is not the trunk-registration minimum in t9xctu. [cite:1]
Same organization
Calls optimize only inside one organization. Interorganization media goes through the PSTN for regulatory reasons. [cite:1]
Recording path
Cloud path. Not optimized. [cite:1]
G.711 class
jr1i3r preference 1 g711ulaw, preference 2 g711alaw. [cite:2]
SIP ALG
b2exve recommends turning it off because some ALG implementations break firewall traversal even though signaling is encrypted. Revision line January 21, 2025. re-check [cite:3]
NAT pool
August 13, 2026 update: size the pool so users and devices are not stuck when ports run out. [cite:3]
DSCP
b2exve: Webex App audio Expedited Forwarding (46) on 8500–8599. Video Assured Forwarding 41 (34) on 8600–8699. Device signaling Class Selector 3 (24). [cite:3]
Certificate media return
Call media from Webex Calling toward a certificate-based Local Gateway uses 19560–65535 UDP. [cite:3]
Phone source signaling
Devices row 5060–5280 toward 8934. The September 07, 2026 history line expanded 5060–5080 to 5060–5280. [cite:3]

06 · Config

What you enable, and what you turn off

  1. On desk phones and Webex App, leave media optimization at the default unless you are in a case the article excludes. [cite:1]
  2. On the Local Gateway, configure voice class stun-usage and the G.711 codec class from jr1i3r. Confirm CUBE is at least 17.3 or 16.12.5 before you promise optimization. [cite:1] [cite:2]
  3. Give the gateway a public address or put the phones on a network that can reach it. [cite:1]
  4. Open b2exve before any ACL. Quote 5062, 8934, and the media ranges from the current table. [cite:3]
  5. Turn SIP ALG off. Mark that recommendation re-check because the history line is January 21, 2025. [cite:3]
  6. Validate NAT pool size. That procedure was updated August 13, 2026. [cite:3]

13 · Interview

Oral answers

30 seconds. ICE can keep media direct inside one organization for the app, supported desk phones, and a reachable Local Gateway. Recording, DECT, ATA, and a second organization do not take that path. [cite:1]

2 minutes. The phases are discovery, exchange, checks, and a reinvite. CUBE ICE-lite in that article needs 17.3 or 16.12.5. [cite:1] I quote b2exve for 8500–8699, 19560–19661, 5062, and 8934. I mark SIP ALG re-check because of the January 21, 2025 history line, and I keep the August 13, 2026 NAT-pool sentence separate. [cite:3]

30 seconds, codecs. The Local Gateway guide’s class is G.711 µ-law then A-law. That is not the third-party phone preference list. [cite:2]

2 minutes, delays. ICE and recording each add a small delay at the start. Together it is more noticeable. I will not call a recorded call a direct-media proof. [cite:1]

What you will not say. You will not build the ACL from memory, and you will not call 5061 the trunk destination.
