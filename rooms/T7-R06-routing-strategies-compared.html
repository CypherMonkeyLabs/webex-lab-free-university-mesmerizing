T7 · SIP, routing, and queues

Routing strategies compared

Hunt groups, call queues, and auto attendants are Calling features. Webex Contact Center queues are a different configuration. Retrieved 2026-10-14.

Room T7-R06 Version v0.1 last-verified: TODO Difficulty L3 Est. time 100–130 min Prereq T7-R05 Reading 16 min

Key takeaways

  • upg0eu, dated August 30, 2024, compares Auto Attendant, Call Queue, Hunt Group, and Shared Line Group. Only the call queue adds callers to a queue. Only the auto attendant provides IVR. A call queue and a hunt group say an auto attendant can be used as the IVR. re-check because that page date is older than twelve months. [cite:1]
  • The same table says a hunt group routes on priority and skill with the note “not based on skills,” and it can ring all at once, sequentially, or longest idle. A shared line group cannot. [cite:1]
  • o6rfjeb’s hunt-group caps: Circular, Top Down, and Longest Idle 1,000. Weighted 100. Simultaneous 50. Changing from a 1,000-member pattern to a 100- or 50-member pattern keeps only the first 100 or 50 members. [cite:2]
  • ubg5qd, page header October 08, 2026: a non-skill queue with team assignment defaults to Longest available. A non-skill queue with agent assignment defaults to Circular and can hold a maximum of 1,000 agents. Skill queues choose Longest available or Best available. [cite:3]

03 · Core concepts

Calling objects beside contact-center queues

Queue is not a synonym

In Calling, “add callers to queue” is a call-queue row. A hunt group’s row is No. In Contact Center, a queue is the waiting area ubg5qd defines for calls, chats, or emails. [cite:1] [cite:3]

Hunt-group “skill” is the table’s parenthetical

upg0eu’s hunt-group cell is a check with the words “not based on skills.” Do not teach a Calling hunt group as skill-based routing. [cite:1]

Two defaults

Team assignment and agent assignment do not share a default. ubg5qd prints Longest available for the first and Circular for the second. [cite:3]

Agent forwarding

When a hunt group receives a call and forwards it to an agent, the agent call-forwarding feature does not work. [cite:2]

04 · Ecosystem & sister technologies

Glossary, map, sisters, edges

Glossary

Auto attendant
The Calling object that provides IVR in the upg0eu table. [cite:1]
Call queue
The Calling object that can add callers to a queue and show a specific caller ID number when the call is forwarded. [cite:1]
Hunt group
A Calling feature that rings members in a chosen pattern. Path: Services > Calling > Features. [cite:2]
Shared line group
The fourth column. It cannot take a workspace member and cannot route by priority and skill. [cite:1]
Longest Idle
The hunt-group pattern. Not the Contact Center name Longest available. [cite:2]
Longest available
ubg5qd’s default for a non-skill team queue, and one of two skill patterns. [cite:3]
Circular default
ubg5qd chooses Circular for non-skill agent assignment. [cite:3]
Best available
Highest proficiency among agents who meet the skill requirement. [cite:3]
Weight default
If you do not configure a weight on Best Available, the article applies 1. [cite:3]
Queue name
Cannot exceed 80 characters. Alphanumeric characters, underscores, and hyphens. [cite:3]
Channel type
Chat, Email, Social channel, or Telephony. Inbound queues display Telephony by default. [cite:3]
Transfer to the same agent
An optional toggle on the Queues list. It applies to all queues of the tenant. [cite:3]
India caller ID
For the hunt-group number as caller ID, the hunt group’s location and the agent’s location must use the same PSTN provider, country, and zone. [cite:2]
Pattern shrink
Moving from a 1,000-member pattern to Weighted or Simultaneous keeps only the first 100 or 50 members. [cite:2]
Location hunt-group cap
The maximum number of hunt groups for each location is 1,000. [cite:2]
Enterprise selection
Not defined on these pages. TODO-verify.

06 · Config

Two Control Hub paths

  1. For a Calling hunt group, sign in to Control Hub and open Services > Calling > Features, then the Hunt Group card. [cite:2]
  2. Choose Circular, Top Down, Longest Idle, Weighted, or Simultaneous, and check the cap on that option. [cite:2]
  3. If the design needs a menu, use an auto attendant. upg0eu says the call queue and the hunt group do not provide IVR. [cite:1]
  4. For a Contact Center queue, open Services > Contact Center, then Customer experience > Queues. Sites, teams, user profiles, multimedia profiles, and skill definitions come first. [cite:3]
  5. Turn skills off for a non-skill queue and notice which default appears. Turn skills on only when you will choose Longest available or Best available. [cite:3]

13 · Interview

Oral answers

30 seconds. Calling has an auto attendant, a call queue, a hunt group, and a shared line group. Only the auto attendant is the IVR. Only the call queue queues callers. [cite:1]

2 minutes. Hunt-group caps are 1,000, 1,000, 1,000, 100, and 50. A shrink keeps the first 100 or 50. Agent call forwarding does not apply to a hunt-group call. [cite:2] Contact Center non-skill defaults split: Longest available for teams, Circular for an agent list of up to 1,000. Skill queues use Longest available or Best available, and a blank weight is 1. [cite:3]

30 seconds, what this is not. It is not an ICM skill group and it is not a parity sheet.

2 minutes, recording and AI. A Telephony Contact Center queue can allow recording. Pause and resume depends on Privacy Shield. [cite:3] AutoCSAT is system controlled. [cite:4]

What you will not say. You will not call a hunt group skill-based.
