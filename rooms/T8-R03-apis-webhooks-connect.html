00 · Header

T8 · Flows, integrations, and the current platform

APIs, Webhooks & Webex Connect

Webex Connect is the programmable CPaaS: channels, a service workspace, Flow Builder, and rules. Inbound webhooks start a flow. Outbound webhooks carry receipts and incoming messages. A Webex Contact Center Task is the unit of agent work, and the tasks API asks for cjp:config or cjp:config_read. Calling recording events already have names on the commercial call-control page. A subscription cap, and webhooks for call queues, are not in those pages.

Room T8-R03 Version v0.1 last-verified: 2026-10-14 Difficulty L3 Est. time 90–110 min Prereq T3-R01, T8-R01 Reading 17 min

Key takeaways

  • Connect’s own page lists six areas: channel provisioning, integration setup, flow orchestration, multichannel messaging, NLP/NLU/AI, and enterprise control. Channels include SMS, RCS, Branded Text, WhatsApp, Push, Live Chat and In-App, Email, Voice, MMS, Apple Messages for Business, and Messenger. [cite:1]
  • Assets are created in the Connect portal, in Control Hub for Email and Chat, or through Developer Portal APIs for those digital assets. A service holds the assets, integrations, credentials, flows, and rules. Flow Builder is the multi-step designer. Rules are the shorter trigger-condition-action path. [cite:1]
  • Inbound webhooks notify Connect about an external event and can start a flow or a rule. Outbound webhooks deliver receipts and incoming messages. Custom nodes wrap REST or SOAP. Authorizations are a service key or a JWT. [cite:1]
  • A contact-center Task is a request for agent work. Telephony is an incoming call, chat is a session, email is a chain. Listing tasks wants scope cjp:config or cjp:config_read. [cite:2]

03 · Core concepts

Name the editor before you name the API

Three editors

Webex Contact Center Flow Designer is T8-R01. Webex Connect Flow Builder designs multi-step customer flows inside a service. An ICM script is the Enterprise editor, and T6-R04 keeps that import marked. Connect’s page also has Rules, which are triggers, conditions, and actions for shorter work. [cite:1]

Host match is not this room

SIP URI host matching lives in T2-R03. Connect Voice on the CPaaS page is outbound notifications, programmable calling, IVR, and call recording for Connect. It is not the Local Gateway dial-peer table. [cite:1]

Do not invent a webhook quota

The commercial pages cited here name recording events and the tasks scopes. The recording pages still do not say a call queue emits telephony_calls. The ceiling and the Calling queue resource are on the Webhooks guide. as of 2026-10-14 the Webhooks guide prints 30000 personal webhooks per user and one org-wide webhook, plus additional registrations for different resources and filters. A Calling call queue emits telephony_queue updated, not the recording events on telephony_calls. [cite:6] The government developer site is a different cloud. [cite:2] [cite:3]

Programmable CPaaS. APIs, SDKs, and low-code tools for the six areas on the product page. [cite:1]

Rules
Trigger, condition, and action for shorter automation than a flow. [cite:1]

Outbound webhook

Custom node
Reusable REST or SOAP call inside a flow. [cite:1]
Service key and JWT

AI Agent Studio
Where Connect says you create and manage AI agents. Fulfillment flows connect agent actions back to Connect flows. [cite:1]
Contact policy
Consent, preferences, and how often you may contact someone. [cite:1]
Task

telephony_calls

convergedRecordings

CRM connector
Cisco’s Salesforce, Dynamics 365, or ServiceNow screen pop. Chat and email are not supported on those connectors. Connect is the digital path. [cite:4]

06 · Config

What to configure, without a sample secret

  1. Pick the channel from the Connect table before you pick a portal. Email and Chat are the Control Hub pair. Other channels follow the portal docs the page links. [cite:1]
  2. Create a service. Put the asset, the credentials, and either a flow or a rule in that workspace. [cite:1]
  3. For a short notification, use a rule. For a multi-step conversation, use Flow Builder and publish it. [cite:1]
  4. Create an inbound webhook when an external system must start that flow. Create an outbound webhook when you need receipts. [cite:1]
  5. Store a service key or a JWT in Connect’s authorizations. Do not commit either value. [cite:1]
  6. If an AI agent must act, connect the action to a fulfillment flow. [cite:1]
  7. For agent work, call the Tasks API with cjp:config or cjp:config_read. A telephony task is the call, a chat task is the session, an email task is the chain. [cite:2]
  8. For Webex call recordings, subscribe to recordingStarting, recordingStarted, recordingPaused, recordingResumed, and recordingStopped on telephony_calls, scope spark-admin:calls_read. [cite:3]
  9. When you list events for convergedRecordings, send serviceType. [cite:3]
  10. Subscription limits and the Calling queue resource are the Webhooks guide. [cite:6] Use the debug console and the user audit when a flow did not run. [cite:1]

13 · Interview

Oral answers

30 seconds. Connect is the CPaaS. A service holds the channel, the flow or the rule, and the credentials. Inbound webhooks start work. Outbound webhooks report it. A Task is the contact-center’s unit of agent work, with its own scopes.

2 minutes. I name the channel before the API. Email and Chat can be Control Hub or the digital asset API. SMS, WhatsApp, and the rest follow the portal. Flow Builder is not Flow Designer. Rules are the short form. Custom nodes are REST or SOAP with a service key or JWT. AI agent actions use fulfillment flows. I can list the five recording events and spark-admin:calls_read, and I send serviceType with convergedRecordings.

30 seconds, tasks. Telephony is a call, chat is a session, email is a chain. The scope is cjp:config or cjp:config_read.

2 minutes, boundaries. I will not quote a webhook quota from a forum. I will not claim call queues emit telephony_calls until a commercial page says so. I will not read a government developer page into a commercial tenant. Chat lives in Connect, not in the CRM gadget.

What you will not say. You will not paste a sample org id or a JWT. You will not call an ICM script a Connect flow.
