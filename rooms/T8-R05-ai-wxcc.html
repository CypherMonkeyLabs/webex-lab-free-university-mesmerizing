04 · Ecosystem

Ecosystem and sister technologies

Cisco AI Assistant
A paid add-on for Webex Contact Center, generally available as of the article header October 06, 2026. Agent Desktop shows an icon. The administrator can turn features off. [cite:1]
Dropped call summary
An AI-generated summary when a call disconnects, so the next agent can continue. [cite:1]
Virtual agent transfer summary
A summary of the virtual-agent portion when the contact reaches a human. [cite:1]
Mid-call summary
On consult or transfer. As of that article, only direct agent-to-agent consults and transfers. Queues, entry points, dial numbers, and organization contacts are not supported yet. [cite:1]
Auto CSAT
Predicts a satisfaction score from operational data, transcripts, and surveys. Supervisors see it in Analyzer and on Interaction Details. [cite:1]
Real-Time Assist
Live recommendations on voice and digital. [cite:1]
Scripted AI agent
Predefined rules and a training corpus. Selected in Flow Designer as Webex AI Agent Scripted. [cite:2] [cite:3]
Autonomous AI agent
Goals and a knowledge base, with less human intervention. Voice access is currently limited to specific customers. [cite:2] [cite:3]
AI Agent Studio
Where agents are created. Voice preview works when Studio is opened from Control Hub > Services > Contact Center. [cite:3]
Virtual Agent V2
The Flow Designer activity. Outcomes: Handled, Escalated, Errored. [cite:2]
Knowledge source
Files, articles, or websites for autonomous agents. Do not upload PCI, PII, PHI, or other sensitive data. [cite:3]
Connect AI Agent node
Digital flows on Webex Connect. Process Message and Close session. The onTimeOut line says the agent hasn’t responded in not more than 15 seconds. The page does not print a timer setting. [cite:2]
Six digital channels
As of s0qro1, header August 25, 2026: WhatsApp, SMS, Email, Facebook Messenger, Apple Messages for Business, Live Chat. [cite:2]
Custom event
Voice only, for scripted and autonomous agents, as of that article. Syntax for an expression is the flow variable form the article prints. [cite:2]
Global_Language
Set before Virtual Agent V2 to override the Studio language, for example fr-CA. [cite:2]
UCCX Alpha
ncs9r37 lists UCCX as an Alpha consumer of scripted and autonomous agents, beside WxCC, WxCCE, UCCE, and PCCE. [cite:3]

05 · Flow

Attach an agent without renaming it

  1. Create the agent in Studio. The CCX workbook has no virtual-agent sheet. [cite:3]
  2. For voice, put Virtual Agent V2 on the flow and pick a published agent. [cite:2]
  3. Override language only with Global_Language set earlier in the flow. [cite:2]
  4. For digital, use the Connect node on one of the six channels named in s0qro1. [cite:2]
  5. Leave the Assistant icon to Control Hub. nvvv1zb describes a desktop icon, not this activity. [cite:1]
