T8 · Build, integrate, operate

Troubleshooting methodology

Control Hub call troubleshooting, trunk status, and registration-gateway validation. This is not an invented protocol stack. Retrieved 2026-10-14.

Room T8-R06 Version v0.1 last-verified: TODO Difficulty L3 Est. time 90–120 min Prereq T8-R05 Reading 15 min

Key takeaways

  • The troubleshooting view needs the full admin, read-only admin, or support admin role. It shows calls for the past 21 days. Calls appear after the call ends. [cite:1]
  • Search keys are email addresses, phone numbers, MAC addresses, call IDs, and correlation IDs. Status is Successful, Refusal, or Failure. [cite:1]
  • Quality grades for Webex Calling are Poor, Good, or None / Not available. The view cannot necessarily provide the root cause. Meetings and Call on Webex are not graded that way. [cite:1]
  • Trunk status updates every 3 minutes: Online, Offline, Impaired, or Unknown. Errors 2, 6, 11, and 12 are shown only when all edge proxy nodes have the issue. [cite:2]
  • Config Validation is only for registration-based Local Gateways. It does not validate the PSTN or PBX dial plan. [cite:3]

01 · Executive summary

After the call ends, then the hop

  • The troubleshooting view needs the full admin, read-only admin, or support admin role. It shows calls for the past 21 days. Calls appear after the call ends. [cite:1]
  • Search keys are email addresses, phone numbers, MAC addresses, call IDs, and correlation IDs. Status is Successful, Refusal, or Failure. [cite:1]
  • Quality grades for Webex Calling are Poor, Good, or None / Not available. The view cannot necessarily provide the root cause. Meetings and Call on Webex are not graded that way. [cite:1]
  • Trunk status updates every 3 minutes: Online, Offline, Impaired, or Unknown. Errors 2, 6, 11, and 12 are shown only when all edge proxy nodes have the issue. [cite:2]
  • Config Validation is only for registration-based Local Gateways. It does not validate the PSTN or PBX dial plan. [cite:3]
Why it matters. The order is the call view, then the trunk, then registration validation. A debug is last, and it has a CPU brake.

03 · Core concepts

Order taken from the articles

Segment, then hop

frj1efb: Alice to an auto attendant is one segment. Auto attendant to Bob is another. A correlation ID ties segments of the same call. [cite:1]

The grade is not the cause

The article says the view identifies the problem area and cannot necessarily provide the root cause of a poor call. [cite:1]

Validation is a narrow tool

2zx7fg validates Webex Calling dial-peers and the registration pieces it lists. It says the complete dial plan, PSTN, and PBX dial-peers are not validated. [cite:3]

Debugs have a brake

jr1i3r’s DS 64224 disables all debugs and uninstalls diagnostic signatures when CPU is at 75 percent or more. The sample FTP username and password are not copied here. [cite:4]

06 · Config

Where each check starts

  1. Confirm the role, then search after the call has ended. [cite:1]
  2. Read status, then the hop, and note whether media used ICE or the cloud. [cite:1]
  3. If the path is a Local Gateway, open the trunk and read status. Remember the page updates every 3 minutes. [cite:2]
  4. For a registration-based managed gateway, start validation at Services > PSTN & Routing > Gateway configurations > Manage Gateways, then Validate. [cite:3]
  5. Before a long debug on the IOS XE Local Gateway, install DS 64224 from the guide. Do not paste the sample FTP credentials. [cite:4]

13 · Interview

Oral answers

30 seconds. Wait until the call ends. You need a full, read-only, or support admin. The window is 21 days. The grade is not the root cause. [cite:1]

2 minutes. Split the call into segments with the correlation ID, then read the hop for ICE or cloud. If a trunk is involved, status is online, offline, impaired, or unknown, every 3 minutes. Errors 2, 6, 11, and 12 mean every edge proxy is affected. [cite:1] [cite:2]

30 seconds, validation. Registration-based only. It does not grade the PBX or PSTN dial plan. Results are stored two years. The gateway data used for the run is removed after 8 hours. [cite:3]

2 minutes, debugs. Install DS 64224 before a long debug. At 75 percent it disables debugs and uninstalls signatures. The guide’s FTP sample is not a credential you repeat. [cite:4]

What you will not say. You will not invent a seven-layer method.
