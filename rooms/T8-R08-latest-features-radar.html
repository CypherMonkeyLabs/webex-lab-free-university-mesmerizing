03 · Core concepts

Dated sentences, not a roadmap

Announce, then restrict

The October 7 country list is not a Cisco Calling Plan order form. g1gtsdb puts the Calling Plan limits next to toll-free and non-geographic numbers. [cite:1] [cite:2]

36 months is one sentence

nv7abhz says authorized full administrators and Contact Center service administrators can request up to 36 months from supported repositories, beyond the 13-month Analyzer and Search API window when extended retention is enabled. This room does not merge that sentence with a Search API FROM/TO limit. [cite:3]

Can help is the page’s verb

Personalized AI Routing “can help” optimize a custom KPI, reduce handle time, and increase CSAT. Those are the page’s claims about help, not a measured result printed as a number. [cite:3]

October 29 is a cutover

Granular agent states roll out to all Webex Contact Center customers on October 29, 2026. Enabling them is optional until then. If they turn on without rebuilt adherence groupings, real-time adherence reporting is interrupted. [cite:3] [cite:5]
