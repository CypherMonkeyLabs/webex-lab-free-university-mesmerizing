Canon / Start

Fundamentals to the marked edges

Start here

Read Control Hub before a dial plan, and the contact-center overview before a queue. The 30/60/90 sequence is a Canon study plan. It is not a Cisco learning path and it does not promise an exam result.

Prerequisites

  • T1-R01 is the first room. Every later track assumes you can find a user, a location, and a service in Control Hub.
  • Calling rooms assume T1-R01. T2-R03 assumes T2-R02, because a dial plan’s routing choice is a trunk or a route group you already know how to name. T2-R06 is TLS, SRTP, Calling end-to-end encryption, recording, and RedSky.
  • Contact-center rooms assume T3-R01. T3-R03 is the queue article. T3-R04 is the desktop. T3-R07 is Analyzer. T8-R01 is Flow Designer before T8-R03’s APIs. T8-R05 is AI Assistant and the AI agents the articles describe.
  • T6-R04 assumes T3-R01 and T4-R01. The calling migration is T6-R02 and stays a different project. T6-R01 is Canon planning for a 2,000-seat scenario. That seat count is the scenario, not a Cisco scale number.
  • T5-R02 assumes you can tell Dedicated Instance from multi-tenant Calling. Read T2-R02 first.
